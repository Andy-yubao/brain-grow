# 数据协议

## 固定权限

使用本地既有数据，模型种子为 11、数据根为 20261004。当前静态 MNIST H1 阶段沿用 3,200 个训练 ID 和 800 个验证 ID；另有 1,000 个历史探索性测试 ID，因已有历史反馈，不视为全新独立测试。官方测试集及剩余封存 ID 保持关闭。

训练和候选生成只使用训练集；结构接受与选模使用验证集，并记录反馈次数。探索性测试仅在所有分支冻结后按预登记规则使用，不据此调方法。输入为原始 28×28 灰度图展平；增强方案作为训练先验披露，不把坐标、ID 或标签送入推理结构评分。

## 既有循环平移实验

2026-10-09用户正式授权本轮继续该循环任务，使用原3200训练/800验证ID及旧验证8位置。[新执行登记](h1_functional_edges_v1_execution.md)中训练ID固定2560/640重构拟合/诊断、每ID4训练内位置；640诊断ID不参与候选拟合排序，但仍可用于端到端任务训练。它不是新增外部验证集。官方测试、历史探索测试和剩余ID均不读取。本条更新下段“已完成独立任务”的当前适用状态，不改旧实验。

2026-10-08 曾单独完成全位移均匀循环平移 MNIST 诊断：同一原 ID 的变体始终留在所属集合，验证每个原 ID 有 8 个固定位置；该实验的 6,400 个验证变体仍只对应 800 个原始笔迹。它是已完成的独立任务条件，不自动替代当前静态 MNIST 协议。结果见[报告](reports/2026-10-08/h1_translated_edges_v1_mnist_circular/h1_translated_edges_v1_mnist_circular_20261008.md)。

数据文件、环境和 ID 清单留在根目录；任何数据范围、测试权限或种子变更须先登记，不因研究方向变化自动解封。
