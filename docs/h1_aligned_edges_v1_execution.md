# H1逐层节点对齐：归一化全局剪边与充分适应 v1

## 授权与边界

2026-10-08用户恢复自主训练，暂时放弃删点、缩点和物理清理。新FC固定784→3136→1568→128→10，非输入节点4842，四层初始权重边由程序核算为7577856。旧6272/3136/256宽度、两倍节点要求及旧损伤图均不沿用。CNN复用[已有扩容基线](../experiments/runs/capacity_baseline_v1/mnist_static/summary.json)，不重训；CNN有效展开边433680仅由报告进行外部验收，最终FC目标≤520416。配置和剪边器不接收CNN边数、卷积层配额、像素位置、邻接、距离或平移共享组。

初始化骨架、ReLU、dropout、增强、全局幅度/RMS评分、每阶段删当前边的一半、每类别至少一条输入边保护均是披露的先验。分类保护适用于所有输出行，不识别数字身份。模型不共享权重；密集Linear+固定零掩码执行不能自动称稀疏加速。

## 假设、对照和接受

假设：相比旧小幅任务敏感删边，一次删除50%的低归一化幅度边、8轮学习率重启适应，可迅速获得更大结构收益；同骨架密集FC自蒸馏可能保持稀疏分支功能。

先新训对齐FC，最多50轮、至少25轮，首次达到完整800验证集97%后结束，按准确率优先、CE次优冻结最佳验证快照；若50轮仍低于96.5%，保存门槛不足并结束本轮，不搜索种子。只用模型根11和数据根20261004，3200训练/800验证；全部候选冻结后每臂一次1000历史探索性测试。官方测试及剩余封存ID不读取。

四臂均从同一冻结FC起点：fixed固定图；magnitude层活边RMS归一化后跨层全局幅度排序；distilled同剪边规则加冻结密集FC自蒸馏（权重0.5、T=2，教师eval）；random匹配distilled逐层删量及接受时序，连接身份均匀随机。每臂5阶段×8轮，固定图也每8轮重启余弦学习率1e-3→1e-5。输入增强和批次顺序按根11+轮数固定，分支相同。蒸馏额外教师前向成本单列，不能称同计算预算。

主剪边候选删当前全图活边50%，不按层固定比例；输出每行最高评分活边保留，剪边仍严格凑满全图删除量。8轮适应后，相对冻结基线准确率损失≤1pp、CE增加≤0.06且导出变小则接受，不逐候选硬守97%。拒绝恢复权重、mask、Adam、RNG（含CUDA），然后原图按相同轮号8轮适应；候选预算与已经耗费成本不回退。阶段全局RNG快照之外不保留流：每轮增强/排序流由预登记轮号重建。快照在zero_grad(set_to_none=True)后取得，无待用梯度；LR在下一轮按阶段日程重建，无独立scheduler。

冻结阶段按完整验证集先筛功能保持（上述基线相对容差），再取真实非零边最少、准确率/CE打破同规模并列；所有阶段均保存，不用1000测试挑阶段。若只有起点合格则如实报告0结构收益。最终约97%功能与≤520416是外部验收，配置不保存该边目标；低准确率不称成功。
