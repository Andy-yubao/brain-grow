H1：未形成小卷积窗口，不等于没有任务相关的结构；可能存在入出度不均、首层空间偏好、重复连接或第二层群组。H0 条件参照：保留每一行和每一列度数后随机重排边，再保留每一行非零权重多重集随机映射到新边。

度不均只描述容量分布；它本身不构成高于度匹配随机图的规律。只有超出登记随机对照的偏差，才称本轮可见的额外组织；没有偏差也不等于证明完全无规律。

## 冻结指标与控制

1. 两层入出度的 0/10/25/50/75/90/100 分位、变异系数、top10% 边占比、孤立节点；输出不可达节点和边仅统计，不删除。权重支撑采用 `(sum W²)²/sum W⁴`，并报告与真实入度的比值。
2. 首层只作外部几何评价：静态用平面，循环任务用 28×28 环面最短距离，计算二值与 W² 加权的连续中心最小 RMS 半径。环面每一轴枚举 28 个断点间隔的解包均值并取最小目标，不把边界两侧误判为远离。另报告最佳 3×3 窗口连接比例和 W² 能量比例（循环窗口包边，静态窗口补零）。CNN 理想完整 3×3 的二值 RMS 为 sqrt(4/3)≈1.155；这个尺度参照不读取 CNN 权重。
3. 第一层重复：入度≥9、空缺≥9节点按入度及编号排序，固定等距抽取最多128个；二值模板按最小二值半径中心对齐，带符号权重按最小能量半径中心对齐。二值逐行减去均值后比较 cosine，带符号权重作 L2 归一化 cosine；报告全对均值及最近相似度中位数，精确重复比例单列，不把高密度公共边或孤立单边称卷积模板。静态对齐嵌入55×55，循环对齐仍28×28；null 使用同节点、同流程。
4. 两层图组织：B = Drow^(-1/2) A Dcol^(-1/2) − sqrt(drow) sqrt(dcol)^T / E；这个 degree 校正消去仅由容量不均造成的秩一分量。固定随机子空间16列、幂迭代2次求前8奇异值；报告第一奇异值、前8残差谱能量占比。固定8簇，对左右奇异嵌入各运行20次迭代的确定性 kmeans；报告8×8块边富集 observed/expected 与 sum((observed−expected)²/expected)/E。随机图也重新拟合，消除“任何图都能聚出簇”的基线。群组指标为探索性描述，不提供显著性 p 值或语义类别。
5. 第二层没有像素坐标，不按编号绘制空间邻接；抽样重叠及带符号 cosine 在原节点标识上比较，不作空间对齐。

6. 首层广域空间权重规律：完整28×28带符号权重场含零边，逐行减均值去DC后统计傅里叶低频能量占比，固定|kx|≤3且|ky|≤3、排除DC（48/783频率）；不看结果调整阈值。两任务FFT均按周期展开，只与各自同处理null比较，静态边界解释受此限制。这可描述广域平滑/纹理相关，不能当局部卷积证明。

每模型、每层2个独立随机流，从观测图独立开始，进行8×该层行数次 curveball 两行交易；保公共边，互异边随机分配，严格保持所有行列度。每行非零权重多重集通过随机映射保持。随机分析根20261004，与模型种子11用途分离。保存原图与各null及两null间的边重叠率。谱另报告第一奇异值平方/完整残差Frobenius能量。没有证明链充分混合：这些是度匹配启发参照；2个控制不足以推断统计显著性，不用它们挑模型或调指标。
