# 扩容后的 CNN/FC 基线执行登记

2026-10-08，用户要求同步扩充 CNN 与 FC；两者基本测试准确率须达到约97%，若仍偏低则立即终止本轮任务。此登记在新模型训练前冻结。

结果完成后仅将面向用户的“选择集/旧control”称呼统一为“验证集/探索性测试集”；划分、门槛、预算和实际执行均未改变。

## 假设与结构

旧一层卷积 CNN 与 784→512→256→10 FC 容量不适合作为本轮参照。新 CNN 为 Conv3×3/stride2/pad1，1→16，输出14×14×16=3136；第二层 Conv3×3/stride2/pad1，16→32，输出7×7×32=1568；展平后 FC 1568→128→10。层间 ReLU，第一 FC 后 dropout0.2。卷积的空间邻接及位置共享是人工先验，仅作为参照。

新 FC 为四个线性层 784→6272→3136→256→10，前三层后 ReLU 和 dropout0.2。相应隐藏层节点数为 CNN 第一卷积、第二卷积及首个 FC 的两倍；10 类输出不倍增。层数、宽度、激活、卷积结构及展平输入均为先验。FC 与 CNN 参数量明显不等，只比较效果并分别报告参数、文件和资源成本，不称参数匹配。

## 数据、训练与停止

数据根20261004、模型根11。仍用已隔离的3200训练/800验证样本；旧1000 control 在两臂冻结后才各评价一次，称探索性测试集。官方测试集和其余封存 ID 不读。两臂相同逐轮样本顺序与仿射增强随机流，增强只用于训练：±12度旋转、横纵各≤0.08图宽平移，零填充。原灰度图作验证/测试。预定标准 AdamW，初始lr0.001、最小0.00001的50轮余弦日程、weight_decay0.0001，batch64、FP32、单根。每轮评价验证集，可按准确率最高、交叉熵最低的预定规则选冻结轮；至少训练25轮，最多50轮，25轮后若验证集≥97%即可提前冻结。

“97%左右”操作性门槛为两臂冻结验证准确率均≥96.5%，且一次探索性测试准确率均≥96.5%；同时报告交叉熵、混淆矩阵及曲线。任一臂达到预定轮数仍低于验证门槛，则停止后续新结构剪枝实验，不换种子、不调参追门槛；若两臂验证通过但任一探索性测试低于门槛，同样停止。非有限、显存不足或数据权限异常立即停止并记因。此停止要求覆盖此前持续开展实验的默认安排。准确率门槛是用户工程目标，不是统计保证。

本轮先只训练 CNN、再训练 FC；通过性能门槛后另行预登记新 FC 的 H1 剪枝和同规模随机删边，旧架构实验不与新架构直接合并判断。单臂最多50×50=2500更新、160000 fit 样本暴露；两臂合计最多5000更新、320000 fit 样本暴露，选择集最多100次/80000前向样本、旧control至多2次/2000样本。工程墙钟预算先登记每臂最多30分钟，超出则在完整轮边界安全停下报告，不暗中扩大。保存配置和源码哈希、每轮曲线、最佳冻结权重、预测、训练/评价墙钟、GPU峰值及停止原因。普通 dense PyTorch 执行，不以参数/FLOPs代替实测延迟或能耗。
