# H1训练内闭合与自适应恢复：执行预登记

2026-10-08。用户已授权实施并运行。当前状态：预登记、实现、CPU轻检查及四臂完整训练均已完成。训练前由主代理冻结提交`9ba14bb`，源及配置保持不变。检查记录见[check.json](reports/2026-10-08/h1_adaptive_edges_v1/check.json)，结果见[完整报告](reports/2026-10-08/h1_adaptive_edges_v1/report.md)。

## 假设及归因

旧循环平移幅度/节点贡献方法从未加入训练内输出可达闭合，且每候选仅8轮，因此失败不能直接解释为容量不足。本轮检验：同一评分与任务下，训练内闭合自然减少无输出路径边，更多固定图适应及完成适应后的较小步长能否保持功能并进一步减边。闭合收益、直接评分剪边收益、控制器收益分别记录；不声称方法最优、严格收敛或CNN结构发现。

## 固定任务、起点与先验

- 只循环平移MNIST，原3200训练ID/800验证ID、模型根11/数据根20261004。完全复用旧`position_manifest.npz`的6400验证变体和3200训练ID固定单位置校准，所有变体仍按原ID隔离。训练仍每轮独立均匀抽取循环位移；校准只读取训练ID。
- `include_confirm=False`；不重新读取1000历史探索ID、不解封官方测试或剩余ID、不迁移CIFAR。
- 固定784→3136→1568→128→10、ReLU、Dropout0.2、AdamW、FP32、batch64、稠密linear加零权重掩码。全部bias及物理节点保留；只编辑权重/mask。
- 两起点各取归档循环幅度/节点臂`stage_5.pt`完整state，含掩码、Adam及Python/NumPy/Torch/CUDA RNG；CPU检查一次验证其权重/mask与已冻结`model.bgm`完全一致。不从后处理清理副本补配Adam，不启动归档入口、不修改旧证据。
- 四臂：`magnitude_old`、`magnitude_adaptive`、`node_old`、`node_adaptive`。每对使用相同完整父状态、评分、数据、首8轮学习率及随机训练序列；评分仅接收通用权重/mask和训练输入RMS，不读取像素几何、CNN、层配额。
- 初始层宽、输出行至少一条入边保护、节点能量代理、平移增强、控制阈值均为披露的先验。节点法5%为代理能量预算，不是删边比例/性能保证。保留旧评分及原始峰值，避免同时改变评分机制。

## 训练内结构闭合

从当前父图先反向闭合；每次直接剪边后、候选适应前再次按实际非零图从输出反向遍历，清除无输出路径的边，同时清零对应Adam一阶/二阶动量，mask为零边权重/梯度保持零。全部节点与bias维度不变。闭合只在结构操作时执行，不每batch扫描。

完整候选回退恢复闭合前同父模型、掩码、Adam、学习率参数组、RNG；无独立scheduler，周期位置、重启状态、父槽、重试、保留epoch等在controller保存。额外尝试的成本/验证账本不回退。失败候选不得成为下一次重试的训练起点。

## 有限控制协议

每臂最多3个父槽，每父最多3次候选。幅度初始删50%存活mask边，节点初始累计5%能量预算。

旧控制臂每候选8轮，只第8轮验证；失败完整回退后在原父图训练8轮，再进入下槽，强度不减半。此为旧流程加训练内闭合的对照，不能冒称完全未改的历史重跑。

自适应臂首段8轮，首8轮峰值0.001→余弦低值，完全匹配旧臂。若不合格，保持同一候选的权重/Adam继续至最多48轮：第9轮峰值0.0005重启，在余下40轮慢余弦衰减到0.00001附近。固定验证点为8/16/24/32/40/48；每4轮以eval模式测固定训练校准CE。仅最近3个校准CE的极差≤max(0.002, 最小CE×1%)才记作操作性平台。8轮只有两点，不能据此认定完成适应。

在预定验证点首次功能合格即认为该候选已恢复所需功能，保存并接受其完整状态；不遍历完整48轮挑候选期最佳。无需为早已合格的候选强制训满48轮。若未合格且仍改善，继续同候选。固定训练平台还需同时核对相邻预定验证点：验证CE下降>0.002或准确率提升>0.2个百分点，仍视为验证改善而延长；到48轮仍改善则记优化未完成。若16轮后最近3点不平台也未有足够净改善，允许仅一次较低峰值0.00025重启，随后在剩余周期慢衰减；不用重复重启制造无限适应。

达到平台但仍不合格记作“完成本协议适应仍失败”，恢复同父完整状态，强度减半并重新生成候选；幅度50%→25%→12.5%，节点5%→2.5%→1.25%。这是一次有限步长回退机制，非小参数扫描，也不保证识别真实容量极限。成功后沿用当前强度。第48轮不平台/仍下降且不合格记“优化未完成”，完整回退、停止该父搜索；不能据此减半。平台失败重试满3次停止该臂本轮搜索。

## 接受门槛、选模与预算

累计参照固定为旧循环密集FC冻结验证准确率94.0937519%、CE0.22852926，不逐槽放宽。合格条件为准确率≥参照−1个百分点、CE≤参照+0.06。闭合/直接剪边须有净边减少；不是强行压到CNN边数。最终从已保留的完整合格状态按最少真实非零边、再最高准确率、再最低CE选择；保存`model_full.pt`（权重/mask/Adam/RNG/controller）及BGM。初始闭合父图始终是合格退路。

每臂900秒、四臂合计3600秒、峰值显存8GiB；预算含训练、评分、验证、保存/导出和失败搜索成本。候选最大48×50=2400更新；旧臂每槽候选400更新，失败额外原图400更新；自适应理论最多3父×3次×48轮，但900秒仍为优先工程上限。到预算仍未合格记优化未完成，恢复父图，不错误减半。四臂分别占预算，保证前臂不能吞掉后臂预算。不能称本轮找到最佳参数。
