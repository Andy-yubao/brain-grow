## 假设与共同边界

补偿机制检验已有大权重边能否由同节点其他输入承接；门控机制检验不保持旧隐藏响应时网络能否重新分工。两者独立从 `experiments/runs/h1_adaptive_edges_v1/mnist_circular/magnitude_adaptive/model_full.pt` 恢复完整父状态，不顺序继承。父SHA256为 `66f5ccadb2f4f1f804a3f55fb78a2f7f08dd4486e219c1691dc79ce45cb1a21e`；真实边 `[271888,252735,5694,138]`，共530455。固定节点784→3136→1568→128→10，4842个非输入物理节点；偏置另计，不删点。

采用既有循环平移MNIST任务：3200训练原始ID、800验证原始ID及旧8位置，数据根20261004、模型根11。训练内重构拟合/诊断划分不增加数据权限。官方测试、历史探索测试及其余封存ID关闭；不迁移CIFAR-10。循环增强是披露的任务先验，结构评分不读取像素坐标、距离、CNN结构/配额或共享模板。

固定功能门槛：验证准确率≥93.09375%、CE≤0.28852926，不随父模型降低。候选还须真实非零边净减少。首层≤56448仅作结果评价与后续机制升级条件，不能用它生成删边配额。循环CNN第一/第二层28224/225792边，总456000；与静态CNN433680的参照分开。记录第二层与总边，避免结构负担转移。

## 方案一：补偿后的损伤选边

训练ID固定拆为2560拟合/640诊断，每ID4个固定循环位移。仅拟合样本用于候选排序；诊断样本仅报告重构误差，后续任务训练仍用全部3200原始ID。每行仅使用已有非零支持，输入中心化，偏置作为自由截距，父权重为阻尼锚点。

支持集协方差加阻尼，默认平均对角×1e-4、下限1e-8，FP64 Cholesky；数值失败最多3次十倍增阻尼，记录为数值修复。使用补偿后响应损伤乘训练任务节点梯度平方评分，不做幅度/RMS预筛。行内贪心逆矩阵更新，全局队列比较各行下一边；删除集合确定后联合重解剩余权重和截距。受限支持集的逆必须单独求解，不能截取全矩阵逆。

每次代理损伤预算定义为所有层节点的“平均任务梯度平方×平均线性响应平方”之和的5%，在全局行前缀队列中累计补偿损伤；它不是实际任务CE增加5%的保证。最多涉及当前50%边；不要求达到任一上限。每父最多3次尝试、最多3父槽。候选修改后立即清理无输出路径边，同步mask，清零外部重拟合涉及的整块weight/bias Adam状态，包括step；保留物理节点。候选适应8轮起步、最多48轮，固定验证点8/16/24/32/40/48，复用已验证自适应平台判据及学习率重启。平台失败完整同父回退，再将损伤预算减半；预算内仍改善记优化未完成，不冒称容量不足。

首候选增加同父同删除集合的无补偿对照，另加不删边继续训练对照。匹配批次/位移序列、优化器重置及共同轮次；每对照最多48轮。报告补偿前后拟合/诊断误差、删除边原权重分位、直接删除与闭合收益。两小时端到端预算包含对照、求解、失败适应与保存。

## 方案二：任务损失驱动连接开关

独立从共同父起步，只对已有连接设置hard-concrete开关。温度2/3、伸展[-0.1,1.1]、初始非零概率0.999，是本实验选择的先验。联合80轮：前8轮无数量代价，随后48轮线性升至1，末24轮保持；复杂度为所有层预期开启总数除以起点总数，层间统一，不给首层特殊目标。

CE为主，固定原父teacher输出蒸馏温度2、初始系数0.5，第56轮前线性归零。不约束隐藏响应。权重AdamW峰lr0.001、wd0.0001，gate独立Adam峰lr0.01、无wd；80轮余弦衰减至峰的1%，不扫参数组合。额外运行数量代价恒0的同流程对照。

第32/56/80轮分别生成独立硬结构分支：概率<0.5关闭，保留开关确定性系数折入weight，训练内无输出路径闭合，再按最多48轮协议恢复。完成后恢复联合训练全状态，不让分支消耗改变联合路径。最后选功能合格且真实边最少的完整硬状态；软概率不等于实际连接减少。训练检查点保存gate、两个optimizer、controller和全RNG。主臂及对照共享两小时端到端预算。

## 自动升级

两个机制都跑；预算结束后若均无首层≤56448且功能合格结果，登记并运行任务驱动净换边。最小合格模型是起点，支持集外使用线性响应梯度与输入外积获取任务梯度/对角二阶代理，不能使用被mask清零的weight梯度。预计收益选新边，每次最多恢复当前边10%，负梯度方向、该层权重RMS×0.1初始化；8轮承接，再门控/硬化恢复。最多3结构槽、两小时，仅最终净减少且保功能接受。

仍不足则登记重新学习稀疏表示：当前最小合格mask、seed11重置全部weight，从零teacher蒸馏/任务训练与在线替换，沿用80轮联合及硬化协议，两小时。其后根据实际失败证据选机制差异明确的新轮，先登记再实施，不重复阻尼/lr/惩罚系数扫描。单候选失败和单轮预算都不代表H1研究终止。
