# 当前研究框架

## 目标

以普通 ANN 为起点，在训练任务上联合优化参数与连接结构，得到保持任务功能、实际更紧凑的网络。FC 到卷积式连接规模的对比是第一个验证案例，不代表最终优化器只适用于 MNIST。

## 本阶段边界

2026-10-09当前执行采用[功能补偿与门控协议](h1_functional_edges_v1_execution.md)，沿用循环平移任务，固定验证门槛93.09375%/CE≤0.28852926，首层56448作为结果评价与升级依据。下列静态CNN433680边参照属于之前任务，不能用于当前循环任务的成功判定。

- FC 固定为 784→3136→1568→128→10；节点数和层数保持不变。
- 只优化参数和有效连接；不物理删点、不缩点。无输出路径支路清理仅删除边，不删除节点。
- 2026-10-08最新修订：训练的结构操作中清理无输出路径的边，同步掩码及优化器状态，仍保留全部物理节点；拒绝候选须连同清理完整回退。此前暂停不可达边清理的规则由此覆盖。[自适应剪边入口](h1_adaptive_edges_v1_execution.md)已完成四臂实验，恢复训练延长及失败减半实际支持继续减边；完整结论见[报告](reports/2026-10-08/h1_adaptive_edges_v1/report.md)，不是最佳参数或自然稀疏极限证明。
- 优化规则不使用像素位置、局部邻接、卷积模板或 CNN 逐层配额。CNN 只作外部参照。
- 目标连接量约为 CNN 433,680 条有效边的 1.2 倍；连接量达标必须同时保持任务功能。
- MNIST/CNN 是案例，不据此宣称跨任务迁移、卷积规律发现或实际加速。

## 评价与实验

完整报告准确率、损失、混淆矩阵、真实非零边、独立参数、导出字节及训练/搜索资源。每轮先登记假设、对照、预算、接受标准和停止信号；大幅机制尝试优先于小规模参数扫描。被拒绝的结构候选须恢复模型、优化器、调度器、RNG 等相关状态。
