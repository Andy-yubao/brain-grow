# 无输出路径边清理登记

2026-10-08用户询问算法缺口与清理结果。本轮对三个冻结FC另存清理副本，固定全部节点与bias；用户本轮清理要求覆盖此前暂停不可达边清理的边界，不授权物理删点。原训练模型、检查点和历史结果保持。

假设：普通逐层Linear/ReLU FC中，没有非零边路径通向输出的目标节点，其入边不影响输出。反向从全部输出遍历非零边，将不可达目标节点对应行的权重及掩码置零即可；不把样本静默当作删除理由，不使用图像位置、标签或CNN配额。

对照：同一冻结模型原版/清理版，无训练或适应。预算CPU两线程、120秒、无GPU、无数据访问。先以含非零bias的玩具网络检查反向链级联清理；再以固定分析随机根20261004的零、常数、均匀和高斯合成输入共128条，FP32 eval对照输出，检查导出重载与存活参数原样保留。

接受：删除边均指向原图输出不可达节点；节点宽度、bias和所有剩余权重不变；清理图没有残留无输出路径非零边；输出差异<=1e-6且预测相同。失败不宣称清理成功，不覆盖源文件。图结构证明适用于任意有限输入的实数计算；合成输入检查仅核对实现，不替代数据集准确率重测。不读取验证/测试数据，不新报准确率。
