# 研究目标与边界

## 长期目标

面向缺少成熟架构经验的任务，从普通 ANN 出发，让训练反馈共同调整参数和连接结构，学习有效、紧凑且有机会迁移的计算组织。准确率与泛化优先；低性能下的强压缩不算成功。

## 当前阶段

2026-10-09执行重点为循环平移MNIST上的功能替代与重新分工：共同父530455边，比较补偿后损伤选边和任务连接门控；验证功能≥93.09375%且CE≤0.28852926，第一层≤56448为接近循环CNN的外部评价。达不到则自主换边/重学并继续新机制，优化器不接收CNN数量。[执行预登记](h1_functional_edges_v1_execution.md)优先于下段历史静态任务目标。

验证普通 FC 能否在保持任务功能的情况下显著减少真实连接。网络固定为 784→3136→1568→128→10；结构操作限于权重与连接掩码。阶段边数参考为 CNN 展开有效连接 433,680 的约 1.2 倍（520,416），但必须同时保持任务功能。CNN 仅用于外部评价。

核心优化器不得接收图像坐标、距离、局部连接模板、卷积权重共享关系或 CNN 层配额；训练增强及初始骨架等先验需披露。不得为 MNIST/CNN 结果进行反复的小参数调优。用户允许普通 ANN、ReLU、梯度和反向传播。

## 证据层次

分别报告任务性能、真实非零连接数、结构规律、跨规模或跨任务复用。稀疏掩码、独立参数减少、存储收益和实测加速是不同结论；不得从边数或 FLOPs 推断能耗。

## 数据与实验治理

使用唯一模型种子 11、数据根 20261004；原始 ID 隔离。官方测试和剩余封存数据不自动解封。重要实验先登记假设、对照、预算、接受准则与停止信号；运行成本如实分轮记录。
