## 2026-10-08当前新想法：按目标节点输入贡献剪边与跨分布验证

用户提出：在整体剪边基础上，按每个目标节点的输入连接实际影响删边；用CIFAR-10或平移MNIST检验剪枝是否主要利用固定位置/边缘低信息。采纳作为下一机制与验证方向，本次为讨论和资料核对，尚未实现或训练。

当前旧评分按层RMS归一化后跨层全局排序，并非逐层独立剪边。节点贡献可从`z_j=sum(w_ji*h_i)+b_j`出发，以训练集上的`abs(w_ji)*RMS(h_i)`作简单评分，可再按目标节点典型输入尺度衡量相对影响。候选应在每个节点已有入边内筛选，不强制每节点删除相同比例或保留相同入度；联合删除后检查节点输出扰动和最终任务功能，多边相关/抵消与罕见样本不能由均值评分保证。现存恢复训练、拒绝回退与固定物理节点保持。相关既有方法[Wanda](https://arxiv.org/abs/2306.11695)采用权重与输入激活范数及逐输出剪枝；其LLM证据不能直接当作本项目ANN新结果或创新。

需要修正中心偏好解释：已有首层连接中央14×14占26.8%而其面积占25%，像素列度熵0.983；本轮最大连接节省发生在后面密集层。固定位置是待检验混杂，现有证据不足以说成功主要来自丢弃边缘。建议先冻结旧规则在位置均衡MNIST上检验，再同一任务比较全局幅度与节点贡献机制，随后在CIFAR-10验证，避免同时改任务和规则而无法解释差别。

平移方案需区分：较大画布随机完整放置数字可避免裁切，但改变输入大小/容量且边际像素分布未必严格均匀；28×28全位移均匀循环平移可在期望上均衡像素能量分布，保留像素但引入环面及跨边界笔画，CNN边界处理/有效连接基准须另登记。现有小幅仿射增强不是均匀全位移。按原始ID先划分，同一数字所有变体归同集合；验证变换固定，不扩大既有MNIST授权原ID/官方测试权限。

CIFAR-10用于不同自然图像任务的验证，不能先假设它没有中心偏好，不能照搬MNIST约97%门槛；先确认同任务密集FC/CNN学会任务，比较相对性能损失、逐类表现、真实边与成本，节点继续按参照逐层匹配，核心剪边规则冻结。2026-10-08只核对本地`data/cifar10/cifar-10-python-huawei.tar.gz`，170498071字节、MD5 `c58f30108f718f92721af3b95e74349a`与[Torchvision官方源码](https://docs.pytorch.org/vision/main/_modules/torchvision/datasets/cifar.html)一致；未重复下载、解包或读训练/测试样本，尚未划分新任务数据。

辅助方案：固定像素置乱检验坐标/排列依赖，但保留低信息维度，不能代替均匀平移；位置均衡且真实依赖已知的合成任务可区分是否恢复局部/稀疏规律；后期非图像任务验证核心规则通用性。具体操作、数据划分和预算待下一正式执行登记，本轮不改模型或启动GPU。
