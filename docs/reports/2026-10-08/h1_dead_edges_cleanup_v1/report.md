# 固定节点的无输出路径边清理

2026-10-08。依照[登记](../../../h1_dead_edges_cleanup_v1.md)完成三个冻结模型的清理副本；原模型未覆盖，未训练，未读任何图像、标签、验证集或测试集。

## 原因

节点贡献剪边在目标节点内按 `w²×RMS(h)²` 累计贡献筛边，并保留每行至少一条最强入边。它衡量到达该节点的输入影响，不衡量节点是否还有非零路径到输出。下游删边造成支路断开后，上游权重/激活仍可较大，局部评分不保证清理。当前流程没有把反向可达闭合清理作为必要步骤；此前固定节点阶段还明确暂停不可达结构清理。这是流程完整性缺口，不是无输出路径边有预测价值。幅度法也不保证没有支路，只是本次冻结结果较少。

循环节点贡献第二层删除1081428条边，占该层61.10%；第一层删除147598条，占10.86%。清理后两循环模型总边仅差21251（相对幅度约1.123%）。但节点贡献首层仍多307704条，第二层少267675条，并非逐层相同结构。以循环CNN456000条展开边作参照，两者仍约4.15倍、4.20倍，清理未解决有输出路径网络仍偏大的问题。

所有物理节点、bias与保留边权重原样保留。所有删边目标节点在原图无输出路径，清理图此类非零边为0。输出反向归纳保证：可达节点只可能接收可达前驱的非零权重，删去其他目标行不改变任何可达节点计算，因此在有限输入的实数计算中保持完整输出函数。非零bias不影响该证明。

FP32 CPU eval：含非零bias的玩具网络级联检查通过；每模型128条零/常数/均匀/高斯合成输入，原版与导出重载副本最大logit差均0，预测全同；导出重载状态逐张量全同、源SHA不变。没有重测数据集准确率、损失或混淆矩阵；同函数意味着数学上保持原任务预测，不把合成输入通过写成新准确率结果。

## 后续修复边界
