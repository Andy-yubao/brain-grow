# 幅度与节点输入贡献组合讨论

2026-10-08。用户询问是否尝试综合方式，以继续收紧第一层。已核对最近循环平移与自适应配置/分支：幅度与节点贡献各自运行，没有组合臂。此前幅度＋蒸馏是不同组合，不能视为本方案已验证。当前仅讨论/核对保存统计，没有启动训练或读取新数据。

## 合理性与限制

全局幅度用层RMS归一化幅度跨节点/层选边；节点法用`w²×RMS(h)²`在每个目标节点累计低能量入边。节点评分已经包含权重幅度，不是与幅度完全独立的信号；逐节点累计预算仍与全局排序有不同分配偏好。类似权重与输入激活乘积的评分也见[Wanda](https://arxiv.org/abs/2306.11695)，其LLM结果不证明本项目ANN组合有效。

只读旧`history/ann_stages_20261008/experiments/runs/h1_translated_edges_v1/mnist_circular/node/calibration_stage_1.npz`中`input_rms_0`：784列均值0.336010963、总体标准差/均值0.018007746、最小0.317967743、最大0.353931487；第2—5槽保存值相同，输入校准本身不依赖模型。这个固定3200训练ID单平移校准样本上各像素RMS很接近，不是一般任务保证。均匀循环平移在期望上使每像素二阶矩相同；因此首层节点评分近似常数乘`w²`，与幅度排序可能高度重叠，不能默认两者组合能突破首层瓶颈。未测所有边排序相关性，不能给出重叠比例或说两法完全相同。

当前幅度/节点最终第一层271888/530028，但两机制继承的是不同旧父模型；不能仅据这些数字宣称幅度评分在同起点严格优于节点评分。

## 建议的有限组合验证（尚未预登记/实现）

从同一个当前幅度自适应完整状态开始，比较继续幅度、改用节点贡献、两者交替三臂；保持同数据/节点/根、训练内闭合和自适应恢复、统一工程预算。每次操作后重新训练/校准，再生成另一机制候选，避免一次连续两刀后无法区分伤害来源。分别报告实际训练和验证反馈数量，更多删边不能仅由组合臂多训解释。不据第一层CNN配额设置删除量，不把继续三槽或成功作为必须实现的配额。

另一可选方式是全局幅度提议＋逐节点累计影响约束，用局部预算约束全局操作，可能减少损害集中于少数节点；它本身更保守，不保证额外省边。直接取两候选集合并集可能放大联合损伤，取交集可能只是保守少删；未归一化的两分数直接相加没有清楚尺度含义，均不作为首选。

如组合仍难压首层，优先多边联合影响与剩余权重补偿：单边代理省略输入二阶交叉项，不能识别相关输入上共同抵消或可重构的连接。以训练激活/输出功能生成联合删边与补偿候选，保持全部节点、记录净非零边，并用充分适应和验证接受/完整回退；不能把有限训练重构当作全域等价。此方向不输入像素位置、局部邻接或卷积先验。
