# 研究计划

## 当前已完成

节点固定 FC（784→3136→1568→128→10）的幅度剪边实验达到 236,808 条真实非零边，验证准确率 97.125%，达到本阶段 ≤520,416 条边并保持功能的标准。蒸馏组合未显示全面优势。详细结果见[报告](reports/2026-10-08/h1_aligned_edges_v1_mnist_static/h1_aligned_edges_v1_mnist_static_20261008.md)。

## 下一轮

2026-10-09用户正式批准[完整执行预登记](h1_functional_edges_v1_execution.md)：补偿损伤选边＋同删除集无补偿/不删继续对照；独立任务门控＋零复杂度对照。每机制两小时端到端预算；不足则自主登记净换边、稀疏表示重学及后续新机制。当前实现中，后续以状态页区分检查和运行；下文“未冻结/讨论”保留为历史。

实际两机制及两升级全部完成，[报告](reports/2026-10-09/h1_functional_edges_v1/report.md)显示补偿255837边/93.125%但首层仍172936，其他新结构无合格净收益。下一[跨节点激活迁移](h1_activation_migration_v1_execution.md)已登记并独立实现，直接让同层活动节点承接后继贡献，不围绕门控阈值调参。

训练内边闭合、自适应恢复和失败减半已完成四臂实验，幅度组530455边，第二层接近循环CNN，但第一层仍9.63倍。证据见[报告](reports/2026-10-08/h1_adaptive_edges_v1/report.md)。

下一机制方向登记：固定节点下的多边联合删除与剩余权重补偿，以训练激活重构/最终任务扰动筛候选，尽量处理首层广域输入冗余；通用规则不接收层级CNN目标、像素几何或局部模板。不为当前总边差额10039做微小比例扫描，不通过删点解释收益。此为下一研究方向，尚未冻结具体实验或实施；预算/对照/阈值须先登记，新的训练不能直接从本段启动。

用户最新决定停止节点输入贡献及其幅度组合尝试，之前[组合讨论](h1_hybrid_pruning_discussion.md)不再是待执行方案。优先补偿后误差驱动的联合删边诊断；若保持旧层响应限制了首层压缩，再转任务损失驱动的连接开关和功能重分配，必要时研究净省边的结构替换。方案与约束见[功能替代讨论](h1_compensation_proposal.md)，目前未冻结具体实验或启动。

实验前冻结：

1. 假设和机制边界，说明优化器可见的信息。
2. 对照与共同初始化、数据划分及随机根。
3. 搜索、训练、验证和资源预算。
4. 任务功能接受标准、完整状态回退内容及停止信号。
5. 结果记录字段和失败后下一步。

阶段操作保持节点维度不变；CNN 只作外部参照，优化器不接收位置、卷积先验或 CNN 分层目标。若新机制有效，按证据登记下一轮；若候选失败，保存原因并继续探索 H1。

若更充分适应与自适应步长仍无法有效收紧前层，再优先多边联合功能影响与边替换/补偿，不重复微小参数扫描。方案核对见[讨论](h1_adaptive_pruning_discussion.md)。

## 长期验证

在固定核心规则后，再检验更大 FC 与不同任务上的迁移性。分别证明稀疏性、局部性、重复模式、严格参数共享、存储变化与执行速度；不得由一个图像任务的边数结果推断通用发现或加速。
