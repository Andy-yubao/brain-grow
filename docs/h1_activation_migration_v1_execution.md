# H1跨节点激活功能迁移：后续机制预登记

2026-10-09。方案一把单节点输入功能迁给其余输入，已保功能减少51.77%边，但第一层仍172936。任务hard-concrete在80轮内没有跨过硬阈值，不能提供实际删边收益。已授权的净换边/重学升级正在运行。本轮先实现准备，仅在这些升级仍不足时启动GPU；不预先把正在运行的升级说成失败。

## 假设与区别

多个活动隐藏节点的功能可能近似可由少数同层激活共同承接。直接重构它们对下一层线性响应的总贡献，联合替代其输出边；训练内反向闭合再删除失去输出路径的入边。此为跨节点功能迁移，不继续调整单边gate代价或阈值。全部物理节点、原骨架和bias保留，不物理删点或缩宽。新增无输入/无输出路径节点的数量单列，不以静默节点伪造活动迁移证据。

## 起点、数据与功能边界

取已完成各臂中真实边最少且功能合格的完整父，通过`--parent`指定路径，冻结SHA256。仍为784→3136→1568→128→10、seed11、data20261004，3200训练/800验证原始ID、旧8验证位置，沿用功能替代实验2560拟合/640诊断训练ID和各4位移。640诊断不参与候选排序；端到端任务训练仍用3200。所有测试、剩余ID、CIFAR关闭。

固定验证准确率≥93.09375%、CE≤0.28852926，候选必须真实总边净减少；第一层≤56448仅外部评价，不反推组数、代表数量或每层配额。优化器只读激活、任务梯度/误差、权重及图，禁止坐标、局部模板或卷积共享。

## 候选生成与实际守门

1. 缓存隐藏层post-ReLU拟合激活。候选须实际输出可达、至少1%拟合样本激活、方差正。静默节点不进入迁移组。
2. 按中心化激活相关性组成互不重叠的至多32节点组，贪心稀疏插值选至多4个代表R，其余为D。32/4为本机制披露的操作先验和工程上限，不是必须删点或首层连接档位。不得按权重幅度选节点。
3. 用真实激活拟合被替代贡献`Y=H_D @ W_next[:,D].T`。中心化FP64岭求解代表输出增量，阻尼平均协方差对角×1e-4、下限1e-8；最多3次数值失败十倍修复。偏置补偿均值，原D输出权重置零，代表输出叠加增量，允许新增必要边。
4. 真实净收益=直接删除输出边+训练内闭合删除边−新增非零输出边。净收益≤0跳过；按任务梯度平方加权的下一层响应残差/净收益排序，不按幅度排序。代理损伤累计不超过父任务加权层响应能量5%，不是实际CE保证。
5. 每加一组，在固定训练拟合小批实际CE守门（相对本父增加≤0.005），失败回退该组并试其他组。累计操作后须验证该训练CE门槛，刷新受组交互影响的激活、梯度及候选，而非假定预计算误差独立相加。诊断ID仅报告响应/任务误差。
6. 每父最多检验64组、最多3父槽，允许少量或0组通过，不强行删满。物理节点与其bias保留，立即训练内边闭合并同步mask。重置被改参数的整块AdamW状态，拒绝结构适应恢复父权重/mask/optimizer/RNG/controller。

## 适应与归因对照

候选采用既有8轮首段、最多48轮、固定8/16/24/32/40/48验证点和自适应学习率/平台协议。固定功能合格且净省边方接受。首次候选增加同父、同D、同允许新支持的无补偿对照，以及不删边继续训练对照；匹配序列与优化器重置，对照各最多48轮，在共同轮次归因。

无补偿新支持为零初始化、但必须能学习。实现独立保存“允许学习支持”，不把其预留零边当作真实结构：梯度在相同允许支持上更新，weight非零后同步实际mask，每次更新立即做真实非零图闭合及Adam同步。主臂与对照均使用此流程，关闭的D输出不在允许支持内，不能重生。对照允许支持/起始真实图/最终真实图分别报告。
