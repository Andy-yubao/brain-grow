# 实验原则

## 预登记

训练前冻结任务、数据权限、初始化、参数更新、结构操作、对照、预算、接受标准和停止信号。重要实现与配置哈希、运行来源和恢复入口一并登记。计划、实现、检查、运行、结果分别标明。

## 当前 H1 范围

固定 FC 784→3136→1568→128→10，只编辑参数和连接，不做物理删点或缩宽。优化器不得读取像素位置、卷积模板、CNN 权重或 CNN 逐层连接数。CNN 仅作外部参照。连接目标与功能标准须同时满足；准确率和泛化优先。

## 数据与对照

固定模型根 11、数据根 20261004。训练/候选生成使用拟合集，结构选择和选模使用验证集；按登记完成冻结后才可进行探索性确认。官方测试集与剩余封存数据保持关闭。控制比较应尽量匹配起点、数据、更新与结构规模，并披露不能匹配之处。

## 状态与成本

拒绝候选需恢复模型、掩码、优化器、调度器、梯度、RNG 和相关控制状态；消耗预算及搜索成本不回退。记录准确率、交叉熵、混淆矩阵、真实非零边、独立参数、共享映射、导出字节和资源测量边界。边数、参数数、FLOPs 不等于能耗或速度。

## 检查和报告

只做与本次改动相关的轻量检查，不重复已有通过证据。文档改动后运行 `python -m tools.check_workspace`。报告优先复核已保存证据，明确计划/实现/运行/成功的差别、失败结果和结论范围。
