# 自适应剪边与结构适应讨论

2026-10-08。用户要求先讨论，不启动实验、不修改训练代码。合理建议记录为下一实施方向，具体阈值、预算和对照须另行预登记。

## 现状核对

固定节点静态及循环平移幅度法每次删现存mask边50%，随后AdamW训练8轮；3200训练ID、batch64，每轮50次更新，候选400次更新。每轮学习率按8轮余弦周期重启：首轮0.001，末轮约0.00004768（配置下限0.00001，末轮未正好走到下限）。存活边延续Adam状态，删除边动量清零；不是单纯沿用末期低学习率，但没有充分收敛判据、延长周期、提高峰值学习率或存活动量重置对照。每候选仅末态验证，未按候选期最佳验证保存。

循环平移节点贡献法并非固定删50%边：每个目标节点删除累计不超过5% `w²×RMS(h)²` 的低能量入边，且保留至少一条入边；5%是代理能量预算，不是准确率损失保证或边比例。该法同样训练8轮。

循环幅度第3/4/5候选均失败，仍各删约947232边。节点法第2—5候选均失败。最后槽节点候选增强训练CE第6/7/8轮0.18421/0.17134/0.16840，仍下降；增强/Dropout造成噪声，不能据此确认收敛或保证延长必定恢复。现有证据不支持把失败视为结构容量极限。

两流程拒绝均恢复本次全部删边及候选适应前的权重、mask、Adam状态、学习率参数组和RNG，丢弃候选适应；随后原结构再训练8轮，保留正常更新。以前已接受的删边不会恢复。无独立scheduler对象，学习率由epoch/周期公式设置，控制阶段另外记录。失败后下一槽不缩小50%或5%预算，而是在适应过的原图重新评分再尝试。

## 下一实施要求

用户明确：无输出路径边清理放在训练期间的结构操作中，不能仅以末态清理作为修复。下次在提出候选后、适应训练前从输出反向闭合清理，固定物理节点及bias，同步mask/删边优化器动量；完整候选回退也回退清理。接受结构操作后保持此不变量；后续恢复连接时需允许有意重开并重新检查。结构清理无需逐batch重复。后处理工具仍保留为历史诊断，不宣称训练内已实现。

## 建议的控制流程（尚未冻结/实现）

1. 从当前已接受图做训练内闭合，评分仅基于保留图。动态提议强度是操作步长，不是最终边数目标；不读CNN配额或图像几何。
2. 先检查联合删除对训练校准样本节点激活/输出损失的扰动。此代理用于缩小明显过大提议，不能代替最终验证，不能保证罕见样本或样本外。
3. 候选固定图上以学习率重启适应，保留8轮作为首段评估而非自动终点；观察固定训练校准集的eval损失与有限频率验证。若持续改善则在预登记有限预算内延长较慢衰减周期；保存预定评估点的最佳验证候选。不以单次噪声判断平台，不通过增加验证次数挑分。
4. 未稳定且未达门槛记作优化未完成或预算耗尽；不要当作结构不可行，也不要因此自动减半强度。若震荡先处理学习率；若训练拟合好、验证差，按泛化失败处理。
5. 达到预登记适应终点后仍失败，完整回退到同一父图，强度减半重试。幅度法例50%→25%→12.5%；节点法例能量预算5%→2.5%→1.25%，实际删边量自然决定。每次从同一父图重新生成候选并独立训练，不沿用失败候选权重来冒充回退。记录所有训练开销，有限重试/最小强度/总预算后退出此父图搜索，不把边数继续下降作为必须完成配额。
6. 成功且恢复容易可维持步长；接近接受边界或恢复慢则缩小；连续裕量充足才谨慎增大。最终评估对固定原任务参照设累计损伤限制，避免相对上一轮逐次放宽造成性能漂移。

首先比较旧控制器与自适应控制器（同评分/数据/初始化），独立登记训练内闭合收益和实际成本，避免同时改很多评分方法而无法归因。对前层额外做逐层小候选诊断，区分第一/第二层敏感性；诊断身份不进入通用优化器的CNN层配额。若更充分适应和较小步长仍不能有效剪，才优先多边联合重构补偿/通用任务敏感度评分，而不是继续扫描微小比例。学习率重启已有[学习率回溯论文](https://arxiv.org/abs/2003.02389)支持作为候选，但不证明本项目8轮或更高峰值一定足够。
