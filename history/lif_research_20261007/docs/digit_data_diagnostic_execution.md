# 数字数据轻量诊断登记（2026-10-05）

用户授权一次小规模、轻量GPU测试，并确认前一GPU任务已结束。目的为区分数字尺寸与初始角的影响，不预先认定数据损坏，不替换v5主协议或主LIF模型。本轮沿用已授权非SNN对照的通道CNN；结论首先适用于该探针，不能直接外推为SNN机制结论。

## 四组配对设计

| 组 | 前景对角线 | 初始角 |
|---|---|---|
| small_full | 10–11.5像素 | 原全圆[-180°,180°) |
| small_narrow | 10–11.5像素 | 原角线性缩至[-15°,15°) |
| large_full | 18–20.7像素 | 原全圆[-180°,180°) |
| large_narrow | 18–20.7像素 | 原角线性缩至[-15°,15°) |

各组28×28原灰度、8帧、7运动和原数字标签相同；顺/逆净旋转仍±105°，所以“窄初始角”不意味着所有帧正立。大数字要求改变几何空间：四组共同平移距离4.1–4.4像素，位置按最大前景的共同安全区确定，保留1像素边距。起点位置与平移由原v5抽样的归一化分位线性映射，不新增随机数据种子；同尺度两角组中心和尺度逐项相同，同角两尺度组全部轨迹逐项相同，仅尺度为1.8倍。共同缩短位移/收窄位置改变了原任务，不能用本轮绝对分数直接宣称原14像素位移任务已解决。

保留原160拟合ID/40控制ID及顺序，4480/1120视频、每ID4 variant×7运动；每类16/4笔迹。只提取原200训练ID的原始像素，标签沿用manifest；原100验证ID和余下封存ID不参与生成或前向。不扩大笔迹、不换根20261004/模型11；本轮不能判断扩大笔迹覆盖的因果收益。保持原一次仿射、4倍双线性与BOX渲染，不增加特征。原缓存与manifest不修改。

## 模型、优化与预算

使用相同初始权重的[通道CNN](../src/braingrow/network/ann_controls.py)：8→32→64→128卷积、两次MaxPool2、6272→256→17；1,704,945参数，隐藏ReLU。17 logits分别数字10/运动7，每视频独立；全部参数训练，AdamW foreach=False，lr恒0.001、weight_decay=0.0001、数字CE＋运动CE、梯度范数裁剪1，批量128。FP32、确定性、关闭TF32，无预训练、无额外增强或调参。

每组20遍/89600优化视频次/700更新，四组合计优化前向与反传各358400、更新2800。控制第5/10/15/20遍各1120，共16次/17920；拟合第10/20遍各4480，共8次/35840。共同一次真实32视频GPU诊断，沿用[已验证诊断](../tools/train_ann_comparison.py)：前向160、反传96、3次更新含重放；模型/优化器/RNG恢复逐位核对，梯度与视频隔离有效，随后全部回到种子11初始权重。全部检查点和预测保存，不按最佳控制检查点选取成绩。

GPU总工程墙钟上限15分钟，按完整遍边界保存并停止；不因结果不理想额外加遍。不超过20遍、不调学习率或种子。数值非有限、数据/配对/源哈希不符立即保留证据停止；OOM不自动换配置。先渲染每组小样本，核对纯尺度/角度配对、安全边距、原v5渲染复现；通过才生成四组全量并启动真实梯度诊断。

## 判读规则与保存

主要指标为控制数字准确率，第15/20遍平均作为有限预算效果；同时报告末态数字/运动/联合、拟合与控制差距、损失及三种混淆矩阵。分别算小尺度/大尺度下的窄角收益、全圆/窄角下的放大收益与交互项。平均增益≥5个百分点且末态同向，仅称“初步支持”；不足或反向不作明确收益结论。低分组末态数字拟合<70%时，未观察到收益不能排除该因素；本轮不保证收敛、不作显著性或准确率上限结论。同ID28视频相关，按40ID另报配对差值。

资源列参数、激活位置、GPU/进程内存、实际成本与墙钟；CNN的Fire、生长、神经仿真不适用，不称实测能耗。生成帧检查实际非空及边距，并用独立大画布渲染检查裁切；几何未越界不等于不存在信息损失或捷径。

执行入口：[train_digit_data_diagnostic.py](../tools/train_digit_data_diagnostic.py)，运行目录`experiments/runs/digit_data_diagnostic_v1/`；恢复为项目根目录`.venv\Scripts\python.exe -u -B -m tools.train_digit_data_diagnostic --resume`。各组按遍保存模型、优化器、NumPy/Torch/CUDA RNG、成本账目及上一检查点；源快照/配置/数据SHA固定，已完成恢复不重训。报告预计`reports/digit_data_diagnostic_20261005.md`，尚未运行的结果不得记为完成。
