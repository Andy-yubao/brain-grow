# 5000原始笔迹SNN：轻量启动，用户执行

2026-10-06用户授权主SNN使用最新扩大版数据重新实验，并要求提供命令、先修改AGENTS.md使每次检查轻量快速。本轮采用已生成审计的`data/cnn_5000_v6`，目录名沿用数据生产实验，不代表SNN使用CNN特征。4000拟合/1000控制原始笔迹、112000/28000视频，原v6像素、4轨迹×7运动、根20261004及既有划分不变；不提取新封存ID，不读取原验证或最终测试。此次最新授权将同一扩大版训练覆盖用于SNN，原仅CNN阶段限制保留为历史记录。

## 执行方案

[新入口](../tools/train_snn_baseline_5000.py)沿用[已验证v6训练流程](snn_baseline_v6_execution.md)，固定5000/3000/2000隐藏LIF及17累积输出，共10017单元、24954000边权；只训练边权，隐藏间只传Fire，泄露率/阈值固定，暂不生长/剪减。输入uint8灰度仅转float32除以255，不添加特征。每视频8帧、32个5ms神经步、160ms神经时间，视频时间归一化0至1，无规定物理帧率；视频开始清零。

从根11重新初始化，不继承旧权重。数字与运动硬标签交叉熵等权相加，AdamW(foreach=False)、lr=0.001、weight decay=1e-4、裁剪1，有效批量128、微批量32，FP32/最高矩阵精度、关闭TF32、确定性算法。每2轮及末轮控制反馈：连续2次控制损失未相对改善1%则下一轮lr减半，冷却1次评价，下限1e-5。累计最多25轮，恢复不额外加轮数；沿用数值/发放故障保护，不增加平台早停。控制最佳按数字/运动/联合准确率之和保存，拟合集每5轮及末轮评价；全部预测、混淆矩阵及逐层/帧/视频Fire保持记录。

仅一次8视频启动检查：无标签校准至多3前向，共至多24视频前向；随后一次8视频前向/反传检查四组梯度，0优化更新，不做GPU恢复重放、不重复全量像素审计，恢复不再启动诊断。同进程准备和训练复用一次数据哈希/标签/ID预检。训练自身仍按正式预算运行，不能把25轮大样本训练称为轻量检查。

完整25轮上限：优化前向/反传各2800000视频、21875有效更新；控制13次/364000视频，拟合5次/560000视频。显存保护只减少微批量，不缩层宽；OOM尝试和中断回放额外计账。阶段转换、缓存哈希、环境、源码快照与实际成本存运行目录，不把计划记为结果。扩大前后每轮视频量相差25倍，成绩比较不得称等预算或独立ID单变量消融。

## PowerShell命令

```powershell
Set-Location "E:\project\brain-grow"
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe -u -B -m tools.train_snn_baseline_5000 --resume --epochs 25
```

首次从头准备，已有目录则恢复，总预算须保持一致。Ctrl+C在训练批次边界保存退出，再次执行同一命令恢复。结果独立保存`experiments/runs/large_lif_baseline_5000`；旧v5/v6模型与CNN保持。暂停请求同入口加`--request-stop`，只CPU预检使用`--check-only`，仅启动检查使用`--prepare-only`。最佳`best.pt`、完整恢复`resume.pt`/`resume_previous.pt`、逐轮JSON、真实评价预测及降率日志保存规则沿用v6入口。

本次代理只做一次CPU入口预检（4.60秒，缓存哈希、4000/1000原ID及标签维度通过）和一次文档/语法检查，不启动GPU、不重跑旧行为测试；真实8视频检查和训练在用户执行命令后发生。
