## 模型、数据与优化

三个架构直接复用[现有ANN模型](../src/braingrow/network/ann_controls.py)：`video_mlp`为6272→2500→2000→2000→17（24,720,517参数）；`stacked_cnn`将8帧作8通道（1,704,945参数）；`cnn_gru`逐帧共享卷积，接128→256的单层GRU（1,196,433参数）。用户已授权非LIF对照；主研究边界不由此改变。所有参数从根11默认初始化开始，不继承v5模型或轻量诊断权重。GRU每视频状态归零；模型只接收8×784原灰度，不接收标签、原始ID或位姿。

[独立训练入口](../tools/train_ann_baselines_v6.py)调用[v6专用加载器](../src/braingrow/data/moving_mnist_v6.py)，只解包训练成员，检查缓存、manifest和渲染源码哈希。当前缓存SHA256为`479a4784b54b3b79d7a12cdb827d3ae85636dec8d499ff97b94b9f20866c5145`。三个模型共享4480拟合/1120控制视频，160/40原始MNIST笔迹隔离，数据根20261004；验证1400视频与最终测试不解包、不前向。数据与样例详见[v6报告](../reports/data_v6_20261005.md)。旧v5 SNN成绩不能作为同数据参照。

目标为数字10类与运动7类交叉熵等权相加，训练全部参数。AdamW(foreach=False)，初始lr=0.001、weight decay=1e-4，梯度范数裁剪1，有效批量128。FP32、最高矩阵精度、TF32关闭、确定性算法、4个CPU线程。三臂共享根11批次随机流，顺序执行，不安装依赖，不修改其他GPU任务。

## 控制反馈与预算

[反馈组件](../src/braingrow/ann_feedback.py)以控制集两任务交叉熵之和为反馈，每2轮评价一次，第25轮也评价。一次有效改善须比此前有效最佳损失相对降低超过1%，小波动不重置耐心计数。

- `ReduceLROnPlateau`：连续2次控制评价无有效改善，将下一轮lr减半，最低1e-5；不采用固定轮数降率。
- 早停：累计至少10轮，控制损失连续5次评价无有效改善则结束该模型，继续下一个。降率不重置早停计数，使降率后仍有训练机会且不无限延期。早停可能反映平台或泛化恶化，不代表收敛。
- 最多25轮，拟合集每5轮评价；预算结束或早停轮额外保证末态拟合评价。控制最佳按联合准确率选择，平分依次数字、运动、较早轮；与损失早停依据分别记录。

每臂正常完整25轮：优化前向/反传各112000视频次、875更新，控制13次/14560视频次，拟合5次/22400视频次。三臂合计优化前向/反传各336000、2625更新，控制39次/43680，拟合15次/67200；早停减少优化和常规评价，若早停轮不是5的倍数，末态拟合额外最多一次/4480视频。冻结各臂控制最佳后再拟合评价一次，各4480、三臂13440视频次，不再更新或选择。按实际运行计数，不将上限记为发生。

每臂先32拟合视频真实GPU诊断：输出/梯度、模型＋优化器＋NumPy/Torch/CUDA随机流更新恢复重放、视频批次隔离及帧序敏感。每臂160前向/96反传、3更新（含一次重放），三臂480/288/9；诊断更新全部撤回，正式从第0轮初始化及原随机流开始。非有限损失、梯度或恢复不一致、显存故障停止并保留现场，不自动换种子、缩网或重试失败诊断。

## 执行、停止与恢复

在PowerShell复制执行以下命令；`--resume`也支持首次启动，新建臂先诊断，全部通过才开始正式训练。没有运行中的进程时，再次执行同一命令会恢复已有检查点，完成或早停的臂不会重训。目录锁拒绝同一目录重复启动。

```powershell
Set-Location "E:\project\brain-grow"
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe -u -B -m tools.train_ann_baselines_v6 --resume --epochs 25
```

只想先做实际GPU诊断，可在末尾加`--prepare-only`，随后去掉该参数启动训练。只检查数据和配置、完全不运行模型，使用`--check-only`。单独运行一臂可加`--arms video_mlp`、`--arms stacked_cnn`或`--arms cnn_gru`；默认顺序全部三臂。首次采用自定义`--outdir`或`--batch-size`后，恢复须沿用相同参数、源码与数据，预算10–25轮且不可中途改变。

结果保存在`experiments/runs/ann_baselines_v6/<arm>/`：`config.json`、源码快照、每轮指标、预测NPZ/混淆矩阵、`cost_journal.jsonl`、`resume.pt`、`resume_previous.pt`、`best.pt`、`best_meta.json`和`result.json`。最佳文件保存最高控制联合准确率模型；恢复文件保存最后完整轮的模型、优化器、全部随机流、调度器及早停计数。停止原因区分`completed`、`early_stopped`、`stopped`；完成全部指定臂后生成根目录`summary.json`。

手动安全停止：另一个PowerShell在项目根执行`New-Item -ItemType File -Path ".\experiments\runs\ann_baselines_v6\STOP" -Force`，在当前轮完整保存后退出。移除这个明确路径的文件，再执行原命令恢复。Ctrl+C/强制结束保留上一完整轮；恢复会重放尚未保存的在途轮，成本日志另计额外工作，25轮指完整逻辑轮数上限。诊断阶段被中断的臂不得直接训练，须先检查其现场。
