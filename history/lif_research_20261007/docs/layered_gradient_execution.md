# 分层LIF梯度生长：首轮执行登记

2026-10-04。用户授权启动分层LIF梯度生长路线，并指定使用本机RTX 5080及GPU版PyTorch。旧A1/B1、A2/B2证据不覆盖。本文件先登记D0诊断与固定宽度基线；动态加点、删边和加层须依据D0实际结果继续登记，不将未运行部分记为完成。

## 假设与对照

先检验两个各512 LIF的相邻层全连接图能否通过代理梯度形成任务功能。若固定图仍接近机会水平，先检查Fire、梯度、损失与输出竞争，不盲目大量出生。若建立功能且出现平台，保留共同训练起点，再比较固定图继续训练、全连接批量加点、加点后删边；最终宽度的固定图作为容量对照。加层单独进行，不与加宽混合归因。

## D0实际配置与预算

- 输入固定v5：8帧×784原灰度；每帧4个5ms神经步，共32步/160ms神经时间，视频播放时间未规定。模型种子唯一根11，数据种子20261004。
- 两层各512个LIF，前向第一层接原灰度电流，第二层只接第一层上一神经步的真实Fire；固定泄露系数`exp(-5/20)`、发放阈值0.5，不训练偏置、泄露或阈值。输出固定17个不Fire、不leak的实际电位累积单元，末态分组比较。
- 仅训练输入→第一层、第一层→第二层、第二层→输出三类边权；前向Fire为硬阈值，反传使用`1/(1+5|v-threshold|)^2`代理导数。两个末态分组各用交叉熵，损失相加。AdamW学习率0.001、weight decay 0.0001、梯度范数裁剪1。
- 200个训练原始ID按每数字前16/后4固定分为拟合160 ID/4480视频与结构控制40 ID/1120视频；不解包原100个验证ID数组，最终测试封存。这个控制池参与训练过程中的停止/结构选择，不称独立验证。
- GPU批量128；先16视频D0检查梯度、两层真实Fire、输出脉冲重建、两种加点的出生瞬间功能保持。D0通过后基线最多12遍，至少6遍；控制分数（数字＋运动＋联合准确率）连续3遍改善不足0.002时阶段停止。12遍是本次工程预算，不称训练完成。最多53,760训练视频前向及同数反传、13,440控制前向与48个D0诊断前向；实际发生多少逐轮记账。
- 若D0出现失活、饱和或无梯度，停止并诊断，不以扩容掩盖训练故障；若固定图始终无功能，停止结构生长。若仍在改善但达到12遍预算，记录未完成并另行登记延长，不以预算耗尽称收敛。

D0入口为`.venv/Scripts/python.exe -B -m tools.run_layered_gradient --smoke-only --outdir experiments/checks/layered_gradient_smoke_v1`；通过后固定图入口为`.venv/Scripts/python.exe -B -m tools.run_layered_gradient`。完成/中断后检查点`experiments/runs/layered_gradient_v1/baseline_resume.pt`；恢复加`--resume`。运行目录含配置、开始提交和工作区差异、源码快照、逐轮日志、控制输出、准确率与混淆矩阵、逐层Fire、GPU峰值内存、实际成本。固定图获得可用功能后，再登记加点/剪边的独立预算与接受门槛。

## D0与前12遍实际结果、续训决定

前12遍实际训练控制池数字/运动/联合达到27.946%/51.518%/15.357%，训练损失降至2.1242；逐轮结果仍在改善，故预算到期不等于收敛。固定图为1024隐藏LIF、17累积输出、输入/层间/输出边401408/262144/8704；第12遍控制池平均1598.20次真实Fire/视频，每LIF每步0.04877，第二层仍有55个静默LIF。实际成本为53,760训练前向与同数反传、13,440控制前向、12次控制指标评价，另有运行入口D0的48次和基线入口D0的48次。基线阶段墙钟79.83秒、GPU分配峰值约262MiB、进程峰值工作集约1.62GiB。混淆矩阵与全部逐帧、逐视频/单元Fire见运行目录`best_control_metrics.json`及`best_control_outputs.npz`；原验证与最终测试未前向。

按预登记的“预算到期但仍在改善则另行登记延长”信号，同一固定图和优化器从第12遍续训，预算增加到最多36遍，延长最多额外107,520训练视频前向及同数反传、26,880控制前向；最少轮数已满足，控制分数连续3遍改善不足0.002仍可提前停止。恢复入口为`.venv/Scripts/python.exe -B -m tools.run_layered_gradient --resume --epochs 36`。该延长仍是固定图基线，不触发加点或剪边。
