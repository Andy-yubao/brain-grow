# v6三层SNN基线训练入口

2026-10-05用户要求提供PowerShell训练命令。本轮已将[新入口](../tools/train_snn_baseline_v6.py)接通v6专用训练加载器和[25轮预算](next_training_budget.md)。由用户执行训练，CPU数据/配置预检确认4480/1120视频、160/40原始ID隔离及缓存/清单/源码哈希；12项预算、真实LIF行为及学习率调度恢复相关检查通过，没有代理启动GPU模型训练。检查不证明新模型准确率，真实GPU大图诊断等待用户执行。

## 模型与预算

固定5000/3000/2000隐藏LIF、17个非Fire非leak累积输出，共10017单元、24954000边权。只训练四组相邻层边权；LIF阈值和泄露率固定，隐藏间只传Fire。每视频8帧、每帧4个5ms步，共32步/160ms神经时间，视频序列归一化0至1，无规定物理帧率；所有视频开始清零电位、脉冲和输出。

使用v6原灰度784维输入、4480拟合/1120控制视频，原始ID160/40隔离，数据根20261004。验证与封存测试不解包、不前向。新模型从根11从头初始化，不继承v5权重。当前先训练固定v6视频基线，不刷新在线轨迹、不生长或剪减；此选择用于明确测量数据协议修改后的从头学习效果。

目标为数字与运动硬标签交叉熵等权相加，无标签平滑；AdamW(foreach=False)、初始lr=0.001、weight decay=1e-4、梯度范数裁剪1，有效批量128、初始微批量32，FP32/最高矩阵精度、关闭TF32、确定性算法。显存不足仅减微批量，维持层宽和有效批量，额外尝试独立记账。

控制集每2轮及最后一轮评价。控制损失连续2次未相对改善1%时，下一轮lr减半，冷却1次评价，最低1e-5；调度器和随机流随检查点完整恢复。控制最佳模型按数字/运动/联合准确率之和选择，与降率指标分别记录。拟合集每5轮及最后一轮评价，保存混淆矩阵、实际逐层/逐帧/逐视频Fire及每LIF每步发放统计。

总预算最多25轮，恢复不重置轮数，不设自动预算延长或旧50轮最早停止条件。连续3优化批梯度全零、非有限损失/梯度、连续2控制评价某层发放率<=1e-5或>=0.95时停止并保留证据；人工安全暂停另行支持。达到25轮仅表示预算结束，不称收敛。

完整25轮优化前向/反传各112000视频、875有效更新；控制13次/14560视频，拟合5次/22400视频。启动先用固定32拟合视频做最多3次无标签校准（至多96前向）及32前向/32反传梯度诊断，0优化更新；实际大图诊断在用户启动命令后执行。全部成本按实际发生记账，中断回放/OOM额外尝试不隐藏。

## PowerShell命令

从项目根目录执行，`--resume`在目录不存在时从头准备，在目录存在时恢复；总预算与初始登记必须一致：

```powershell
Set-Location "E:\project\brain-grow"
$env:PYTHONUTF8 = "1"
.\.venv\Scripts\python.exe -u -B -m tools.train_snn_baseline_v6 --resume --epochs 25
```

Ctrl+C会在当前有效批次后保存并退出；再次执行同一命令继续。另一个PowerShell可提交暂停请求：

```powershell
.\.venv\Scripts\python.exe -B -m tools.train_snn_baseline_v6 --request-stop
```

仅CPU预检可加`--check-only`；仅真实GPU初始化诊断可加`--prepare-only`，之后去掉该参数恢复训练。同目录进程锁拒绝重复启动。

结果保存`experiments/runs/large_lif_baseline_v6`：`config.json`记录数据/源码哈希、环境和预算；`prepared.json`记录实际初始化诊断；`epoch_*.json`记录逐轮成绩与成本；`evaluations`存真实预测、混淆矩阵和Fire；`best.pt`保存控制最佳，`resume.pt`和`resume_previous.pt`保存完整安全恢复状态；`learning_rate_events.jsonl`记录每次反馈与降率。训练准备/运行失败不覆盖旧v5实验；源码/数据变化须另行登记新实验，不静默恢复。
