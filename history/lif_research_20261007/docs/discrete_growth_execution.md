# A1实施登记

本轮A1/B1实施范围限定见[只读审查](../reports/growth_implementation_review_20261004.md)，忠实修正版另见[A2/B2登记](growth_revision_execution.md)；原JSON成绩保持不变。

2026-10-04。用户最新授权覆盖旧设计文档“仅设计、不训练”。本轮现在实现并运行A的D0/D1；最终测试未载入；公共缓存加载器解包验证数组，但本轮未作验证前向、指标或选择。

机制假设：同一LIF自己的复位前近阈值资格与原灰度/真实脉冲源侧偏，在16正+16负、两侧各至少3原始ID的窗口中持续出现，可以通过小比例离散迁移形成任务结构。输出直接累积每次实际Fire，训练以1/2/5/9/17计数界限记录侧偏；这些档位不进入推断。

实现见[学习器](../src/braingrow/network/discrete.py)与[运行入口](../tools/run_discrete_growth.py)。128随机全部可塑LIF，16–64像素入边、6内部来源、5弱输出边，零偏置、阈值0.5；时间常数10/20/40/80ms。原灰度直接输入，不构造图像特征。内部资格窗口严格取过去1–4步的真实Fire，可跨帧、不可跨视频；复位前电位仅作本单元资格。资格候选记录覆盖全部潜在来源，但缺席边电流为零。其管理内存单独于网络资源报告。

具体事件表的实施细化：隐藏源在正侧≥50%、负侧≤25%或反向，且存在本地资格；同方向连续两覆盖窗口才提名，10%概率选边。异符号先退出，同符号弱变强，缺席变弱。连续两窗无侧偏的幼年边以1%机会强退弱/弱退出；达到两次重复证据的边降为保守候选，不直接成熟删除。每窗另有10%概率为本单元随机选择一条输入或内部来源进行无偏形成/退出。无标签静默/饱和兴奋性适应只读本单元实际活动。上述不是逐边全局接受，也不是梯度估计。人工议程与管理器的非局部监督分配如实披露。

实际迁移在30视频批结束执行；批内图冻结，记录每视频每事件最多一次，正/负各满16后不再累计该侧；两侧ID不足3禁止迁移。样本按变体、运动、ID顺位、数字穿插，两臂完全同顺序。初图发育前向确定一次主混淆议程；半数单元获得主议程，其余按17类循环分配各自基线最大混淆对。议程不进入膜方程，不注入教师电流。

首轮D0最多5×140=700仿真视频次，检查70正常/70零输入，只按活动启动检查调整阈值，不按准确率选参数。D1两臂各10×840学习、10×840发育评价；初图两池各840公共成本，两臂末态确认各840；完整臂另4×840整组功能干预。实际预期合计40,460以内（若D0少于700相应减少），不超原逐臂29,400的保守上限。确认只在每臂冻结后使用一次；干预读同一训练确认池。两次出生机会为第2/4遍末，每批4个，要求主议程至少两覆盖窗口且相同混淆仍存在；这不是规模上限。新生4覆盖窗口之前记未成熟，不按epoch宣称毕业，不在本轮删除新生节点。

停止/转向：完整确认数字/运动均不低于初图、一项至少+5pp且联合+2pp、比仅输出相应任务至少+3pp且改善涉及≥5ID，才登记D2；否则停止A扩展，分析单源统计、隐藏扰动及训练/确认落差，再单独登记B诊断。无输入自发循环或多数单元无法进入近阈值区则D0停止。

管理RNG、输出迁移RNG、隐藏迁移RNG是根种子11的固定子流，不是成绩可挑的模型种子。完整臂出生导致容量/随机数消费不同，需披露，不能宣称严格消除混杂。检查点保存完整学习器、所有数组、窗口/覆盖ID、边年龄、稳定节点ID、议程、出生计数、三RNG、轮次和实际成本。`--resume`从最近完整epoch边界继续，完成检查点不会再训练；中断轮次尚未提交的预算必须额外从日志披露，不能伪称逐批精确续跑。本轮完成后硬化入口：每实际前向额外写独立`cost_journal.jsonl`，后续中断时成本仍向前，模型重放不会丢失已耗成本；本轮第一次中断早于这项硬化，已实际额外1,680次另列报告。

运行：`.venv/Scripts/python.exe -B -m tools.run_discrete_growth`；恢复：同命令附加`--resume`。日志/检查点位于`experiments/runs/discrete_growth_d1/`，生成物不默认加入Git；重要汇总另存reports。仅用项目环境，无新增依赖/支出。神经时间160ms/视频，8帧实际视频播放时长未固定；视频膜/上一Fire/输出每次清零，训练窗口与RNG跨视频持久化。边和Fire是资源代理，不是实测能耗。
