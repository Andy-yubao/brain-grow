# 固定FC快照的任务敏感群组简化：执行登记

2026-10-08，root认可范围与实际7分支预算后定稿。已授权完整实现/训练/报告任务，GPU时段排在门控轮之后；本文件不是运行结果。源提交、唯一CPU检查及实际状态随后分别记录。前期讨论见[候选提案](h1_task_sensitive_basis_proposal.md)，本登记取代其累计四臂预算建议。

## 假设与归因范围

在同一冻结FC快照上，群组误差对下一层功能的损伤比单列激活残差更适合选择哪些活动节点可被多基列代替。母态固定为`experiments/runs/pruning_v1/mnist_static/fc/resume.pt`的第25轮未剪枝FC，根11、784→512→256→10、两层ReLU、FP32、无共享。它是来源/恢复入口，不是等预算最终控制；checkpoint、父registration/config及当前所有调用源SHA在训练前登记并冻结，旧注册源保持可核验。

一阶剪枝敏感度并非本项目首创。[Molchanov等原论文摘要](https://arxiv.org/abs/1611.06440)已描述Taylor近似剪枝损失变化、贪心剪卷积核与反传适应交替；这里只核对摘要，未核验其全部推导/实验。本轮操作是固定FC活动群组重构补偿及联合ΔZ代理，应用与操作不同，不称首创一阶方法或原论文复现。

只用这个母快照，分别诊断隐藏层0和1。逻辑四臂×两层=8，实际7分支：`fixed`只训练一次供两层引用同一末态模型SHA；其余`layer0/1_residual/task/random`各自独立从母快照删8节点，不串联，不回写母态，不累计剪宽。这隔离一次群组选择及等预算适应，不证明长期累计简化或多根稳健性。母态、数据、先验宽度、操作及子流均固定，不扫描阈值或挑种子。

## 严格共享池与系数

3200授权拟合原ID按每类既有顺序前256/后64划分2560系数拟合/640内部留出，索引写registration/提议metadata；标签用于分层和拟合CE导数，不进入激活基列或lstsq。一次母模型带梯度批提取同时保存两层H、下一层Z、逐样本G_Z；参数/母梯度/Adam/RNG不改变。拟合集内部反馈明确包括640的任务导数，不称独立结构选择或确认。

各层所有三候选严格共享该快照H/Z/G、基列、候选池、C库与通道尺度哈希。基列数固定最多64/32，列L2归一化后按最大残差贪心并稳定处理节点ID；只因精确残差0停止，不改预算挑结果。CPU float64无截距`lstsq(driver=gelsd)`求归一化系数A，再C=S_B⁻¹ A S_D还原原激活单位，一次转C32。未入基且拟合激活精确非零、C32至少2个精确非零支持的节点才入池；不用绝对系数幅度阈值。库/池哈希和每个删除列支持数全保存。

池不足8则该层诊断未成立：三候选保留原图，仍各完成250更新和评价，保存消耗与失败原因；不补静默节点、不降数量、不改阈值。全零/单列/多列支持分开记录，不用稀疏小值代替真正删宽。

## 群组功能代理

对D群组、基列B，E_D=H_D−H_B C_D，真实下一层预激活差ΔZ=E_D W_Dᵀ。补偿仅`W_kept += W_D Cᵀ`，删除隐藏行/bias与下一层列，下一层bias不变；不重新拟合所有下一层权重，不引入标签驱动任意新权重或教师。适应后普通参数均可训练。已有物理缩宽/编码与动态恢复helpers原样复用。

逐样本拟合CE对Z的导数由sum-loss取G_Z，避免batch大小缩放。J(D)=mean_n Σ_k |G_Z,nk ΔZ_nk|；Q(D)=RMS_nk(ΔZ_nk/σ_k)，σ为母快照2560拟合Z的固定通道RMS。σ候选中不重算，内部640仍沿用拟合σ；精确零分母/零扰动记0，零分母/非零扰动记inf，不加破坏尺度一致性的epsilon。

前层节点正缩放且出边反缩放，使C相应变化、ΔZ不变；下一隐藏通道正缩放使ΔZ与σ同缩放、G_Z反缩放，因此J/Q在实数计算一致。C32补偿仅舍入容差一致，极端FP32下溢不在精确机制保证内。跨ReLU符号改变、近饱和小梯度均可能令J低估；J不是实际任务变化上界，不假设Hessian/二阶。

- `residual`按C32单列相对激活L2残差排序选8。
- `task`逐次扩展联合D，选使max(J/.01,Q/.10)最小的身份，并列取小ID；每步记录J、Q、归一化分数与主导项。
- `random`从同一池一次均匀选8，`np.default_rng(SeedSequence([11,25,layer_index,0]))`；同库C32补偿、不按选择集接受来决定训练，不是接受匹配轨迹。

母FC拟合近饱和，若各步Q主导，只能支持下游功能误差选择，不能据低J宣称梯度有额外作用。不调阈值使它强行生效。

## 等预算适应与末态判断

所有7实际分支统一fresh AdamW，lr=.00025、wd0、无额外减半，batch64、5轮×50=250正常净更新。相同fit批次顺序由`SeedSequence([20261004,26..30])`派生，每分支恢复母根11 RNG。固定控制同样重置Adam，不保留母旧矩获得优势；新尺寸分支无母Adam迁移。物理宽度分别504/256或512/248，正常槽数/非零边/独立参数/映射及完整无损FP32文件逐轮记录。

所有可提议候选直接固定删8并完成同等250更新，J/Q预保护失败也不早停。适应期间不再提议、不追加候选适应、回退/fallback均0；失败分支是独立研究快照，不污染母态。最终一次判定：母fit/内部固定C32的J≤.01且Q≤.10；末态实际width减少8且完整文件比同预算fixed严格更小；完整select800相对fixed准确率下降≤1pp、CE增加≤.05，fixed准确率≥90%。random同标准仅作诊断标签，不作反馈训练/身份重抽。失败也保留全部成绩，拒绝结构不写回母图。

每轮完整select800，仅末态判定、不根据逐轮结果换日程/选早停模型；最终select复用第5轮缓存，不额外screen256。fit3200末态评价，各分支全部冻结后1000旧control一次/分支重复探索；官方测试及剩余ID封存。control不参与接受。
