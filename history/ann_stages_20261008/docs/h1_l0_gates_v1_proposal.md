# H1逐边可训练hard-concrete门控提案

日期：2026-10-08。状态：**预登记提案，尚未实现、检查或训练**。本文件供主代理确认任务范围；实现提交、运行入口、配置哈希及GPU时段确认后才启动。上轮[非零节点结果](../reports/h1_nodes_nonzero_v1_mnist_static_20261008.md)保留，不追加评价。遵守[数据协议](data_protocol.md)、[实验原则](experiment_plan.md)及[长期入口](long_run_prompt.md)。

## 假设与已有方法关系

H1-L0：拟合标签交叉熵与可训练边门控的期望L0代价共同优化，能形成任务保持、真实文件更小的普通FC有效图。与旧掩码候选不同，结构变量log_alpha本身接受梯度；最终冻结后不再训练门控。先检验主动稀疏化是否发生，再比较学到的门值分配与同层随机分配，不能仅凭边数下降声称连接身份有效。

这是Louizos、Welling、Kingma的ICLR 2018既有机制的受控应用，不称首创。公式核对依据[原论文](https://arxiv.org/abs/1712.01312)第2.2节式10–13及[作者实现](https://github.com/AMLab-Amsterdam/L0_regularization/blob/master/l0_layers.py)。作者L0Dense按输入单元共用门，本轮明确改用每个权重连接一门，三个线性层均参与，bias不门控、不惩罚；不设空间邻接、卷积、节点组或共享参数先验。逐边范围是本轮选择，并非原作者Dense实验的原样复现。

## 唯一固定公式与初始化

对每边记a=log_alpha、潜在FP32权重theta。训练时每层每批采样一个E形门向量，同一批64个样本共享此向量，不采用每样本局部重参数化：

- u取[1e-6, 1-1e-6]内均匀值；s=sigmoid((log(u)-log(1-u)+a)/beta)。
- z=clamp(s*(zeta-gamma)+gamma, 0, 1)，有效权重为theta*z。
- p_open=sigmoid(a-beta*log(-gamma/zeta))，期望活跃边为sum(p_open)。
- 评价与冻结均用z_det=clamp(sigmoid(a)*(zeta-gamma)+gamma, 0, 1)，这里不除beta；冻结权重严格为FP32 theta*z_det。

固定beta=2/3、gamma=-0.1、zeta=1.1；每次优化后a截断到[-log(100), log(100)]，与作者约束一致。不退火温度，不调门阈值，不按成绩选择稀疏度。统一a初值2.5，无额外随机扰动：z_det初始精确为1，避免确定性起点改变父FC；初始p_open约0.9837，随机训练仍会扰动输入到下一层，须披露。作者默认初始化对应drop rate 0.5，本轮较开放初值是已学会任务后的延续选择。

p_open及L0惩罚采用理想Uniform(0,1)的解析期望。实际采样用端点保护Uniform(1e-6,1-1e-6)，因此是其近似统计/惩罚，不能称截断采样的精确期望；不为这一极小差异新增采样诊断或改变固定日程。

优化目标为batch平均CE + lambda_epoch * sum(p_open)/3200，3200是本轮唯一授权拟合规模，三个层合并求和，不逐层归一化。固定lambda_epoch=min(epoch/5, 1)*0.001，门控期共20轮，之后lambda=0且门已删除。最后的单边系数为0.001/3200；它不是lambda=0.001乘平均门概率，也不是照搬作者完整MNIST规模的默认超参数。初始L0项约0.1645，不随选择成绩调整。不附L1/L2、权重衰减、蒸馏、EMA或数据增强。

## 数据、起点与参数日程

唯一模型根11、数据根20261004，3200 fit/800 select；官方测试和剩余封存ID不读。1000旧control只在全部最终分支冻结后各评价一次，继续称重复探索。拟合标签仅用于CE；选择标签不产生门、梯度、lambda或随机置乱。

所有独立前缀从旧未剪枝FC第25轮同一权重克隆，来源experiments/runs/pruning_v1/mnist_static/fc/resume.pt，宽784→512→256→10，ReLU，FP32。保留父权重及其证据；本轮新建AdamW，不改父optimizer。门控前缀另增加535040个a参数；训练时额外门参数、Adam矩、门采样、反传与checkpoint字节均计实际成本。

batch64，每轮50更新，评价batch512、CPU线程2。theta/bias学习率0.00025，第16轮起0.000125；门a学习率固定0.02，仅前20轮。AdamW betas=(0.9,0.999)、eps=1e-8、weight_decay=0。门梯度同样使用这些Adam参数，不能隐式抵消归一化系数。批次顺序按根11派生并保存；L0与无L0门控前缀共用相同的独立门噪声流。门流与批次流分离，随机冻结置乱从根11按层派生且保存，不挑种子或置乱。源码落地时配置固定派生规则和来源文件哈希。

## 三个独立前缀与四个最终臂

| 臂ID | 前20轮 | 第20轮边界 | 后5轮 |
| --- | --- | --- | --- |
| fixed | 仅CE普通FC | 同图重置Adam | 同图CE训练 |
| learned | CE+固定L0日程，theta/a联合学习 | FP32 theta*z_det折入普通FC，删z_det=0边，删除门参数 | 固定掩码CE训练 |
| gate_no_l0 | 同样theta/a学习及门噪声，lambda恒0 | 同一确定性折入与删边规则 | 固定掩码CE训练 |
| random | 复用learned第20轮未冻结theta/a快照，无重复训练 | 每层均匀置乱完整z_det（包含零），冻结theta*z_perm | 同样固定掩码CE训练 |

四个最终臂均从第21轮起重置Adam，theta学习率0.000125，各250更新，同批顺序。固定臂的重置和重复25轮是常规控制成本，不能算结构机制效果。门控前缀不迁移Adam到折入后的权重，避免将乘法折入后的矩宣称等价。

random置乱的是完整门值多重集，不能沿用原位置零门、不能偷偷改用未缩放theta。主/随机冻结时逐层z>0位置数相同，门值分布相同，潜在theta和bias相同；实际FP32非零权重数另逐层记录，若theta精确零或乘积下溢导致与活跃位置数不同须原样披露。活跃位置按z>0建立identity group_index，z=0位置为-1，允许活跃代表值为0；不引入共享。后续更新不能恢复已删边。

learned与random的差异检验**零位置及非零衰减幅度与theta的对应关系**，不是只检验二值边身份。random不再读取select改置乱或接受强度，无额外补偿拟合。其前20轮沿用主臂参数学习与门噪声，只能作为条件于同一母态的身份控制，不能冒称一套独立随机剪枝训练全过程。

gate_no_l0的a仍接受CE梯度；它控制显式L0项的作用，不是固定dropout，也不是完全没有结构变量。fixed与gate_no_l0的差异包含门容量、噪声及优化轨迹，不能单独归因随机噪声。此轮不再增加无冻结臂：确定性折入只将z_det并入theta并删除精确零边，没有额外阈值硬化，预测函数应等价；稠密门训练的真实成本单独保存，已能区别训练正则与部署图。

## 冻结、任务判定与拒绝

全部20轮前缀完成后才确定一次图；不按每轮select选最佳稀疏度或提前冻结。阶段B为独立候选分支，阶段A母态保留theta/a、训练标志、梯度、Adam、调度、门流与所有RNG/游标。完整轮checkpoint保存phase、arm、分叉来源与尝试/净/失败样本成本。阶段预算与候选游标不随拒绝回退，成本逐完整轮持久化，预测缓存账本幂等恢复；复用此前已通过的事务约定。

唯一最终任务判据：learned第25轮完整800 select准确率不低于fixed同轮1pp，CE不高于fixed同轮0.05，fit准确率至少90%，所有指标有限；真实codec_v1文件须严格小于fixed第25轮文件。阶段压缩信号再看是否减少至少20%字节，未达20%如实记小幅简化，不另改lambda。将门训练期的期望边数、确定性零门数、活跃位置数、FP32非零边数、独立参数、实际导出字节分开报告。

接受只在末态一次决定，不触发追加训练、阈值或种子搜索。若失败，保存失败分支和预测，恢复未改动的阶段A母态及其完整状态，记录未获得接受图；不能把恢复母态第20轮与其他臂第25轮当公平末态比较。失败候选第25轮仍按匹配预算报告其效果/大小，作为机制证据而不是成功模型。random和gate_no_l0保持各自固定流程，不依据其选择成绩筛掉坏结果。旧control成绩不参与接受或补救。

部署候选仅保存StructuredMLP的FP32有效权重、bias、掩码及必要宽度元数据，沿用v1真实无损文件。门a、采样状态与Adam不属于部署模型，但完整训练checkpoint成本另报，不能漏掉文件内掩码/索引/压缩头。固定宽度不会物理删除节点，运行仍可为原槽稠密/gather形式；边少或文件小不能当推断加速、训练内存节约或实测能耗。

## 可能的结论与数值风险

- learned相对fixed保任务且文件变小：支持这套固定门控日程促进可部署稀疏图，尚非新学习机制或稳健普适结论。
- learned相对gate_no_l0更稀疏：支持显式L0项有增量，仍需检查性能代价；任务退化不能算成功压缩。
- learned比同母态random更好：单根条件下门值位置/幅度对应有任务信号；无优势或random更好如实保留。
- 期望边数下降但z_det仍无零：说明概率目标与此固定确定性估计之间有间隙，不用额外排序剪枝假造成功。
- 初始开概率较高，规范化后L0单门梯度可能接近Adam eps；任务梯度可阻止关闭或权重补偿门衰减。固定lr/eps/lambda就是本轮检验对象，不能看到结果后调大力度。a截断、有限精度下的饱和也须记录。
- 硬裁剪使某次样本门的任务梯度为零，不代表a总无梯度；期望L0项仍可反传。后续冻结则停止结构探索和恢复，不能称双向可逆门结构优化。
