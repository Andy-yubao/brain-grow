# H1新优化方案：完整路径节点组正则与物理剪宽

2026-10-08训练前登记。用户最新要求转向主动促进剪枝的新优化方案；自然恢复未触发不必强行生效，本轮不恢复、不共享、不追加压力、不延长旧恢复训练。从根11普通FC相同初始化在自然静态MNIST重新进行独立有限比较。实现见[路径模块](../src/braingrow/path_sparsity.py)、[训练引擎](../src/braingrow/path_sparsity_experiment.py)、[入口](../tools/train_path_sparsity.py)、[配置](../configs/h1_path_sparsity_v1.json)。

## 机制与先验

普通FC骨架784→512→256→10，两层ReLU，FP32、初始535818含偏置独立参数，层数/宽度/激活/展平输入和操作集合均人为先验。可训练变量仅原权重与偏置；结构操作为无补偿地物理删除某隐藏层的输入行、偏置和下一层出边列，减少真实宽度和参数槽，不增加新边。不预置像素距离、邻接、局部卷积或位置共享组。

只惩罚输入行范数可被ReLU正缩放逃避；相邻入/出范数相乘也可能受另一隐藏层联动缩放影响。本轮改用完整路径的分组范数。输入前向质量f₀=1；各隐藏层fₗ=Wₗ²fₗ₋₁+bₗ²。输出反向质量r_out=1；隐藏层rₗ=(Wₗ₊₁²)ᵀrₗ₊₁。节点sₗⱼ=√(fₗⱼrₗⱼ)，等于全部经过该节点的输入/偏置到输出路径权重积平方和的平方根。偏置视作固定常数输入，输出偏置不经过隐藏节点，因此不受此项惩罚。多个节点的正缩放入边/偏置与反缩放出边保持路径积不变。

正则R=ΣₗΣⱼsₗⱼ/nₗ_initial，再除以根11初始化的固定R₀。宽度分母和R₀训练后不重算，剪节点不改变存活节点的惩罚尺度。R₀及初始模型文件哈希保存。这个分组路径范数不是L0，不保证权重自动精确为零；小分数、低正则值均不能当成功。实现先替换零值sqrt计算域，再取零值的一阶零次梯度，避免0×inf产生NaN；只用普通反传，不假定二阶可微。

路径正则避免正缩放的动机依据[Path-SGD原论文](https://papers.nips.cc/paper_files/paper/2015/hash/eaa32c96f620053cf442ad32258076b9-Abstract.html)。本轮用AdamW加上述节点分组惩罚与候选控制器，是项目内的具体派生方案，不是论文Path-SGD算法，不声称新颖性。

## 五臂与唯一日程

fc：交叉熵、固定图。plain_prune：交叉熵、以相同路径分数排名提出节点删除。path_fixed：交叉熵+路径正则、固定图。path_prune：同正则并按最低路径分数提出节点删除。path_random：同正则，匹配path_prune实际接受slot、隐藏层和删节点数，仅随机删除身份，无选择反馈接受。

此五臂分别观察普通训练、仅剪节点、仅正则、正则+任务剪节点及同规模随机节点对照。plain/path两臂使用相同初始化、批次、节点评分、删除比例、物理操作、适应预算和保留规则；plain只对同目标fc检查容差，path同时对fc公共效果底线和path_fixed同目标对照检查。额外公共底线让正则不能靠牺牲任务效果换压缩。两臂接受次数和最终规模可能不同，应报告完整性能/规模权衡，不能冒称同最终宽度配对检验。

根11、数据根20261004唯一，不扫描λ、不挑种子。各25轮、每轮3200样本/50正常净更新、batch64，AdamW lr0.001、weight_decay0，第11/21轮减半。前5轮λ=0，第6–15轮线性升到唯一λmax=0.05，第16–25轮保持0.05。连续正则仅path三臂；不据选择/探索结果调强度或日程。

第10/15/20/25轮各最多1候选，隐藏层0/1/0/1；每次取当前隐藏宽度4%向下取整的最低路径分数组，稳定按分数/节点ID排序。无系数拟合、激活留出、结构恢复或权重共享。五臂候选轮都先49个正常批次，然后统一重建Adam，再处理最后正常批次，控制只给剪宽臂重置优化器的混杂。新尺寸候选也用零状态Adam。

主候选先物理缩宽并编码/解码，要求真实width和完整文件字节减少，再适应1批。先256固定分层筛选、再800结构选择，对登记参考准确率下降≤1pp、交叉熵增加≤0.05，适应后文件仍须变小才接受；评价使用纯任务损失，不把正则减少当效果改善。拒绝丢弃独立候选、恢复RNG，再原图同批更新，正常净更新不被吞掉。候选适应的额外成本不回退。

path_random同正则，主接受slot按SeedSequence([11,epoch,source_proposal,layer_index])均匀选同数量身份，物理删宽并适应，无条件接受；选择成绩只报告。主适应后拒绝时，随机也匹配1批试更新并回退，然后原图同批fallback；主适应前拒绝/无候选则随机仅正常更新。逐轮断言随机宽度、尝试/候选/回退/fallback及Adam重置时序与path_prune匹配。

## 数据、预算与接受结论

沿用3200授权fit/800select，输入仅原28×28灰度展平。1000旧control已被多轮探索，本轮只有五臂全部第25轮末态冻结后各评价一次，明确重复探索；官方测试及其他原ID继续封存。确认后不回头改本轮方案。

正常前向/反传各5×25×3200=400000样本、6250净更新。plain/path/random各最多4次适应拒绝额外批次，最多768样本/12更新，优化前向/反传上限各400768、尝试6262。正则递推仅对参数计算，不额外做样本前向；其算术及反传成本仍计入训练墙钟。

每轮选择125×800=100000样本；plain/path主候选最多8×(256+800)=8448；末态fit16000、旧control5000，总评价前向上限129448。随机不额外做候选选择评价。候选编码/解码、适应/回退、参数正则、逐轮文件保存和总墙钟如实报告，阶段1800秒跨全部恢复会话累计，每完整轮与退出时原子保存session_cost，不以旧时间倍率否决。

主要接受结论：fc末态select≥90%；path_prune相对fc及path_fixed仍在登记容差内；真实隐藏宽度减少且文件相对fc减少≥5%。同时比较plain_prune与path_prune的接受次数、性能、节点/参数/字节权衡，以及path_random同规模身份信号；低准确率下强压缩、小路径范数或低loss正则项不算成功，不声称单根统计显著或跨任务通用。

逐轮保存纯CE/总目标/正则、路径分数分位数及数组、fit/select/confirm准确率/损失/混淆、动态width、活跃/非零边、独立参数/共享映射、实际完整bytes、Adam/RNG/梯度/账本和候选事件。物理剪宽会减参数槽，但仍稠密gather执行；不从参数数或字节推断速度、FLOPs或能耗。资源注明设备、batch、精度、线程和计时边界。
