# 扩容FC的任务敏感剪枝执行登记

2026-10-08，依据[新基线](capacity_baseline_v1_execution.md)两臂均通过96.5%操作门槛及父代理实际summary，登记独立H1预算。新基本CNN/FC均旧control97%，允许继续；官方测试不访问。此登记训练前冻结。

## 假设与实现

从同一第28轮冻结FC（784→6272→3136→256→10、25401290含偏置参数）分出fixed、task、random，均保留原ReLU/dropout0.2及仿射增强。检验训练拟合集产生的逐边|w·grad CE| EMA低敏感连接能否删除并保持约97%效果，比同规模随机身份更有用。仅删边、不引入坐标/邻接/共享；层数与宽度依旧人工先验。不是L0、新颖性或泛化保证。

执行普通dense Linear，布尔mask固定删除边，梯度/权重/Adam两矩每步归零；不采用旧逐边group gather。EMA每步0.9旧+0.1绝对w·grad，删除按每层分数topk最小值（原索引并列规则由确定性topk给出，不宣称严格置乱等变）。第2/4/6/8轮开始每层删floor(当前活边×20%)，一整轮增强参数适应后评价800选择集。第一轮给出拟合敏感度；所有权重、偏置均正常反传。固定8轮每臂400净更新，AdamW从统一空状态开始，lr0.0002到0.00001余弦日程，weight_decay0.0001，FP32/batch64，评价512。原基线权重与证据不修改。

候选前在CPU保存完整模型/mask、Adam、EMA、Python/NumPy/Torch/CUDA RNG；拒绝恢复全部并清空候选梯度，在原图同轮、同批次/增强/dropout流正常训练。每轮使用独立固定seed+epoch流，fixed/task/random净保留更新和数据流匹配。主拒绝多出的50更新计入搜索成本，不将其伪装成净训练预算。random仅沿用主接受的时序、逐层数量，用独立固定结构随机流选身份，不按random成绩接受；主失败候选不产生随机剪枝。随机适应不足或效果下降照实报告，不追加预算追赶。

## 接受、导出与停止

每候选须选择准确率≥96.5%，对fixed同轮下降≤0.5pp且CE增加≤0.025；同时按统一实际编码文件较候选前减少。编码为架构JSON头+每层完整packbits位图+按位图序列的活FP32权重+所有偏置，不量化、压缩或保留删除权重。无共享映射，独立参数=活边+偏置；隐藏节点宽度不变，训练Adam/EMA仍稠密分配，不宣称计算/延迟/能耗节约。三臂均同格式，另列基线torch文件避免格式混淆。

最终主选择与一次旧1000control均≥96.5%，对最终fixed选择仍符合0.5pp/0.025，真实文件至少减少20%，支持下一轮结构诊断。控制集全部三臂8轮冻结后才读一次/臂，明称重复探索，不选模/调参。若主最终未过96.5%或基本fixed最终明显偏低，停止本轮后续扩展并保留结果；不改门槛/种子/机制。随机失败不触发主回退。无候选接受或少于20%实际简化，记当前方案不足，不以低准确率压缩成功。

每臂20分钟、CUDA峰≤8GiB、非有限/OOM/权限异常立即停并保存原因。最多三臂1200净更新、76800净拟合样本，主4拒绝额外至多200更新/12800样本，总尝试≤1400、89600样本；每臂8常规select，主4候选select，最终fit三次、旧control三次；候选拒绝时一轮fallback也常规select，选择总≤28次/22400样本，fit9600/control3000另列。实际导出/CPU复制/排序/参数训练/评价分项计时；设备/内存/墙钟均实测。启动前1项真实小CPU模型导出与完整拒绝事务检查，不重跑旧测试或GPU诊断。

入口：项目根`.venv/Scripts/python.exe -m tools.train_capacity_pruning`；运行目录`experiments/runs/h1_capacity_pruning_v1/mnist_static`，拒绝覆盖。每轮保存checkpoint、结构曲线与选择预测；源码/配置/父权重SHA和Git提交保存。完成运行不自动重跑；报告读保存预测。计划/实现/检查/运行/成功分开登记。
