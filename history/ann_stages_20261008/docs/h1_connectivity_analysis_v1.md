# H1已保存连接结构分析登记

2026-10-08，用户要求解释全局幅度剪边并比较当前FC和标准CNN连接组织。此轮为离线分析：不训练、不实例化模型、不前向、不读样本、标签、官方测试或剩余封存ID，不修改任何保存模型。根与数据权限沿用[当前数据协议](data_protocol.md)，节点仅统计不物理清理。

## 假设与固定对照

分析固定节点幅度剪边stage5，以及stage4和未剪密集基线。CNN读取冻结checkpoint权重，只将既有Conv2d核展开为有效连接，排除padding与bias；不把共享参数当展开连接。

H1：剪后首隐藏节点的直接像素邻接可能比同入度随机邻接更局部；H2：控制全局像素偏好后仍有局部/重复模板信号；H3：即使有这些信号，也不等于严格卷积共享或平移等变。没有节点坐标的FC中间层禁止按序号重塑成CNN格点。

固定指标：逐层物理节点、非零边、入出度0/min/p10/p25/p50/p75/p90/max/mean；输入前向潜在功能与输出反向可达、指向不可达节点的边；首层非空行的像素质心RMS半径、包围盒面积/密度、质心半径3内边比例；全局像素列度熵/前10%占比/中心14×14占比；每节点绝对权重有效支持数。CNN报告同直接首层指标、边界核与完整核区别。

随机根固定20261004，总共8张离线首层图：4张每行度匹配、按观测像素列度加权无放回抽样图（列度近似）；4张双边交换图（精确保留行/列度），每张前做10E次尝试，后者来自同一链，不能称独立样本或显著性检验。交换只检验拓扑，不重新分配权重。若交换接受率低，公开接受率和混合不足风险。

模板诊断固定256个非空首层节点：按入度、原节点ID排序后等分位抽样；二值邻接减去四舍五入像素质心，落在55×55相对格点；记录平均两两cosine、每行最近模板cosine中位数及完全相同对齐模板比例。随机图固定同样节点，不选好看模板、不扫描对齐规则。此有限诊断不评价权重函数、缩放规范化、隐藏排列最优匹配、计算复用或深层路径感受野。

感受野图固定展示stage5首层RMS半径排序的10%/50%/90%节点（并列按ID），同时画同节点随机对照和CNN内部完整3×3核，避免只选择局部好看的节点。

输出辅助指标：类别入边数、末隐藏节点列度、类别邻接Jaccard矩阵。严格共享根据参数化/共享映射判断，浮点相等不等于绑定。
