# 首轮正式实施登记：structural_v1

2026-10-07用户授权正式实施、自主开始训练，并允许必要时委派6.1-sol/high子智能体；保持轻量快速检查要求。本登记在查看新训练成绩前冻结。旧归档、原缓存、独立环境及封存权限保持。

## 实际实现和先验

源码：[严格共享模型](../src/braingrow/models.py)、[无损导出](../src/braingrow/codec.py)、[结构控制器](../src/braingrow/structural.py)、[数据入口](../src/braingrow/datasets.py)、[训练入口](../tools/train_structure.py)，配置见[structural_v1](../configs/structural_v1.json)。

固定层数、宽度、ReLU、每层单独共享，前向仍执行稠密gather与矩阵乘法。theta槽位固定分配，但掩码可删边，组ID严格引用同一参数；自由参数数和实际训练分配分开。偏置可训练但本版不剪枝/共享。组值按实际成员加权投影，真实逐边导数经前向矩阵hook捕获，组参数梯度求和。

首版操作单向删边/合组，尚未实现拆组/恢复边、增删节点、增层或模块发现。候选拒绝是完整事务回退，不等于已具备结构复活。候选采用局部修改、全局评价，不称纯局部学习或精确双层优化。

导出FP32无损格式包含宽度、偏置、活跃组值、掩码/映射，比较identity、exceptions、sparse、packed等布局的全部真实字节。压缩同时受浮点数值与结构影响，不能只由字节变化证明架构意义。训练theta槽位/Adam仍是原大小，不把文件压缩称训练内存或计算节省。CNN使用另一种含架构state导出，跨格式大小比较仅供描述，不作方法优劣主判据；主存储门槛比较相同FC协议。

## 首个数据与五臂

先运行synthetic_translated：64维环面输入，两种长度5模板先减均值、L2归一化，幅度1.5–2.0、噪声标准差0.15。模板总量/范数相同；位置独立均匀抽取，不提供给网络。10000拟合/2000结构选择/2000冻结确认，数据根20261004。确认成员只在五臂全部冻结后解包，模板/位置清单只供分析，优化器不读取。

FC、prune、share、joint共同64→128→2、ReLU、8578参数，根11相同初始权重和逐轮批次序列。CNN参照Conv1d 1→8、核5、circular padding2、ReLU、global mean、Linear 8→2，共66参数；CNN局部/共享是明确人工先验。

prune采用低敏感边分批删除：|w·EMA(g)|+0.5w²EMA(g²)。share按数值相邻组投影，不使用几何；这是可复核投影对照，不冒称已全文复现β-LASSO或Weight-Sharing Regularization近端算法。joint交替删边与共享，共享排序分数结合组均值逐边导数冲突及梯度平方启发式。候选每层编辑约5%的活跃边或组，候选不是单一微小编辑。

## 冻结预算和门槛

每臂15轮、批量64（每轮157批）、AdamW lr=0.001、weight_decay=0，FP32、epoch6/11减半。结构臂前3轮预热，之后每轮最多2次候选，总上限20。每候选1批适应，占用本轮原批次更新额度，不增加轮外更新；拒绝适应也记成本，其学习状态被回退。候选成本与普通参数更新分列，净保留更新=尝试更新−拒绝回退更新。

5臂最多750000优化前向样本及同量反传，11775次尝试更新；最多60个结构候选（3臂各20）。每臂每轮完整选择一次（共75次/150000样本）；每候选先看真实导出是否减少，再固定按类别均衡256选择样本筛选，必要时完整2000选择确认，最多120次额外评价/135360样本。末态拟合各1次/共50000样本、冻结确认各1次/共10000样本。不按确认成绩再调规则或挑最佳epoch，所有结果取第15轮。

每候选与FC同轮的完整选择及固定筛选子集分别比较，准确率下降≤1个百分点、交叉熵增加≤0.05，且实际导出字节严格减少。累计损伤对FC同轮检查，不只与上一结构比较。受影响Adam矩归零、全局step保持，非等价优化器迁移已披露。拒绝恢复模型、分组、Adam矩/step、控制器EMA、参数/边梯度、Python/NumPy/Torch/CUDA RNG；候选游标和实际成本不回退。epoch调度和确定性批次生成不在候选中改变，无候选专用随机Generator。

阶段扩大需同时满足FC控制≥90%、joint保持容差、同协议期末文件比FC减少≥20%、存在非零多边共享、joint实测训练/选择/候选墙钟≤FC的3倍。墙钟门槛在整臂结束判定；超限停止扩大，不声称高效。该门槛仅支持进入下一诊断，不等于胜过随机分组或发现卷积；随机匹配/局部性/跨任务仍未验证。

首轮失败即保留结果停止追加相同预算/条件，不自动启动MNIST或fixed。若通过则先登记下一轮，不绕过计划阶段门槛。MNIST3200/800已准备，原1000control尚未提取像素；MNIST训练本轮首个诊断通过前不启动。

wall_seconds的比率边界为每轮参数训练、候选搜索、选择评价与编码，包含GPU同步，排除检查点/预测文件写入、末态拟合及确认评价。完整本次执行墙钟另记current_session_wall_seconds，恢复时明确是本次会话长度而不是历史累计完整墙钟。

## 最小检查与运行

一次CPU行为检查集合覆盖共享梯度求和、批量投影、无损导出、拒绝事务及合成缓存确认边界。一次实际GPU启动仅8拟合样本前向/反传、0更新，状态不继承正式臂。没有额外完整GPU恢复重放或旧审计。启动检查不会在同一运行恢复时重复。

运行目录`experiments/runs/structural_v1/synthetic_translated/`；每臂resume.pt每完整轮原子保存，包含图、权重、优化器、控制器、预算账和RNG。registration保存实现/config哈希，不匹配拒绝混入旧实验。选择logits逐轮留存，最终fit/confirm预测、导出模型和summary保留。训练中每批非有限值保护；OOM/异常停止，已完成轮检查点保留，不自动改变批量。

```powershell

# 仅恢复已存在的同实现、同预算运行
```
