# 候选提案：任务敏感的多节点群组简化

2026-10-08，仅供下一轮决策；未实现、未登记启动、未运行。既有激活残差方案与随机补偿近似持平，路径正则也未证明提高可剪性。本提案改变群组选择的功能代理，不扫描旧λ、不单纯放宽残差阈值、不强行触发恢复。

后续root已选择固定FC25一个快照、两层独立诊断，并复用一次实际fixed训练。正式范围与7实际分支预算见[执行登记](h1_task_basis_v1_execution.md)；下文累计方案仅保留候选讨论，不作为本轮执行规则。

## 要检验的机制

设隐藏激活H，删除群组D、保留K，固定拟合系数C使H_D≈H_K C。下一层原预激活Z=H W_nextᵀ+b，补偿后差为ΔZ=(H_D−H_K C)W_Dᵀ。激活残差大不一定任务损伤大：被删除节点出边弱或多个误差相互抵消时，ΔZ仍可能小。因此候选应按联合群组ΔZ，而非只按单节点激活相对误差排序。

建议在不重新拟合全部下一层权重的条件下，保持C的训练激活最小二乘来源及W_K←W_K+W_D Cᵀ补偿形式。仅重构系数拟合，不更新标签驱动的任意新权重、不训练外部教师、不改下游偏置；原权重/偏置随后才参与同预算适应。这样与已有方法的区别集中于哪些联合删除误差具有较弱任务功能，而不是无约束网络内部功能投影。

## 候选生成规则、快照与尺度

优先建议先在每个固定FC快照上并行提议residual/task/random，严格复用该快照的H/Z/G、基列和系数库，给各候选相同一次适应及原图参考，隔离一次群组身份选择。各快照从固定图继续训练轨迹取得，不把已接受候选带到下个快照；这是局部机制诊断，不能直接证明累计压缩成功。正式登记需冻结快照轮次与总预算。

下文四臂六轮是另一种累计延续候选设计及预算估计，并非已选定的正式日程：首次分叉后各臂权重/宽度会不同，只保证候选生成、基列与C求解规则相同，各自实际池和系数库并不相同。其比较包括后续反馈轨迹差异；不能把它称为严格共享候选池，也不能将末态差异完全归因一次群组选择。应先由root选择快照诊断或累计比较，再正式预登记，不两种运行后挑结果。

建议拟合集仍按每类256/64作2560系数拟合/640内部留出。普通训练50更新/轮，候选层0/1/0，最多3slot/每次8节点。来源用同一根11未剪枝FC已冻结末态；所有臂一致，不读官方测试或其他ID。

固定基列预算建议隐藏层0为64、隐藏层1为32。基列只由拟合激活的归一化列残差贪心选取，不读任务梯度，所有比较臂使用相同规则。它们只是C可用的稀疏支持先验，不把未入基节点全部删除：每次仍最多8节点。系数先对列L2归一化的H_B/H_候选做CPU float64无截距lstsq，再按列尺度还原，固定C32。全零激活明确排除本轮非零群组提议，避免结果又由死节点主导；不以近零阈值偷换非零。

保留非基节点的C行填0，只有该快照基列B参与补偿。一次求解所有非基列，得到该快照系数库；内部留出只验证固定C32，不重拟合。若S_B/S_D为正列范数对角阵，归一化解为A，则还原C=S_B⁻¹ A S_D，随后一次转FP32；补偿使用原单位H与W_D，不把归一化A直接加到原权重。严格共享快照的各候选使用同一库；累计各臂仅沿用同规则各自生成，不保证池/系数相同。固定64/32支持与“最大独立基”不是同一先验，须披露，不冒称找到完整架构或全域等价。

逐样本拟合任务导数G_Z=∂CE_n/∂Z_n，使用sum而非mean损失求导以避免批量大小缩放，建议在独立模型副本上取得而不改变原图Adam/梯度状态。第一代理J(D)=mean_n Σ_k |G_Z,nk ΔZ_D,nk|，保留联合群组误差后再按通道取绝对值，既允许真实功能补偿，又避免不同下游通道的一阶符号抵消。它是一阶敏感度代理，不是实际损失变化上界，不假定Hessian或二阶可微。

第二保护Q(D)=RMS_nk(ΔZ_D,nk/σ_k)，σ_k为该slot未修改模型拟合Z的固定通道RMS；精确零分母且误差非零记inf，同为0记0，不用固定epsilon改变缩放行为。σ在候选/适应中不重算；内部留出仍沿用拟合σ。hidden节点正缩放使H及C按比例改变，但ΔZ不变；下一隐藏通道正缩放同时使ΔZ/σ及G_ZΔZ不变。归一化列求解进一步避免最小范数解因节点单位缩放而改变；该一致性是实数机制性质，C32还原/补偿只有舍入容差下的一致性，不声称逐位相同。系数绝对大小只作诊断，不作接受阈值。

建议新轮唯一固定功能保护J≤0.01（每样本CE一阶代理单位）、Q≤0.10，适用于所有候选臂的拟合与内部留出；不根据结果扫描或调整。640内部留出也只评价未修改模型的拟合任务导数及固定C32；这是拟合集内部反馈，非结构选择集或独立确认。跨ReLU符号切换、大误差及零梯度均可能令J低估，Q与实际任务选择评价是保护，不能把代理当证明。

父FC拟合近饱和，G_Z可能很小，max(J/0.01,Q/0.10)可能主要由Q支配。逐次贪心扩组记录J、Q、各自归一化分数、主导项及并列情况；若始终Q主导，只能支持下游功能扰动筛选，不能据低J宣称任务梯度有额外作用。保持唯一阈值，不据这一现象扫描或放大J。

实际删除列逐列报告固定C32精确非零支持数，分类为全零/单列/多列。若正式目标限定为多节点重构，可预登记至少2个精确非零C32支持才入池；本候选倾向采用此限制，正式登记前冻结，不运行后补筛。不用绝对幅度阈值，因为它会破坏节点正缩放一致性。精确零/非零也受FP32极端缩放下溢影响，机制一致性范围限于正常可表示值。

## 公平对照与群组选择

累计方案建议四臂fixed/residual_group/task_group/random_group，来源、基列预算和C求解规则相同。fixed只继续参数适应。residual_group以单节点相对激活残差排序选8个非零非基节点；task_group从自身候选池贪心扩展D，每一步选择使max(J(D)/0.01,Q(D)/0.10)最小的节点，稳定按节点ID处理并列，最多8个。指标用联合ΔZ，区别于将独立残差直接排序；最后同样检查固定功能保护与任务评价，不需激活残差≤0.05。

random_group继承task_group实际接受slot、层和数量，从自己的同型候选池均匀随机选D，C也由相同拟合规则给出，不利用选择集或残差来接受。若候选池不足以匹配，应明确停止失配，不换随机根或静默降低数量。根11派生确定子流，不挑身份。主拒绝适应的额外成本与原图fallback规则匹配；全部候选轮四臂49批后统一Adam重置控制新尺寸状态混杂。

两主候选均要求实际物理width与完整bytes减少，适应1batch后先固定256筛选、再完整800选择，相对同轮fixed仍为1pp/0.05容差，不需击败fixed。记录J/Q、激活残差、C32、ReLU符号翻转比例、出边新非零数和真实性能，不以更低代理或更激进删法自动称成功。任务组与残差组接受数量可能不同，比较性能/规模曲线；随机组与任务组按实际规模匹配，单根结果不称显著。

## 建议预算与未知风险

建议4臂各6轮：正常76800优化前向/反传、1200净更新；两主及随机各3slot，最多9次拒绝额外576样本，尝试1209。候选拟合/内部留出各最多9×(2560+640)=28800额外前向，求任务导数最多28800额外反传（包含内部留出，不做优化更新）；具体实现应复用同一次带梯度前向的H/Z，避免重提取，不与正常训练账本混淆。epoch选择19200，主候选最多6×1056=6336，末态fit12800/control4000，总选择/末态评价42336。CPU求解、群组贪心及副本成本单列，建议跨resume阶段1800秒。

群组打分可缓存逐节点E_j·W_jᵀ并按需累加，避免同时保存N×候选×下一层通道的大三维数组；需要CPU/GPU内存上限及分块实现。若基列近似不足、任务保护不通过或候选池为空，如实保留失败，不扫描预算/阈值挑成绩。实现前仅针对新增J/Q尺度/梯度获取/联合误差缓存风险做必要最小检查，复用已有模型/GPU/数据证据。

建议工程保护固定为GPU批64、最多缓存CPU H/Z/G/C及单个已选群组ΔZ；各候选增量按最多32个身份×64样本分块即时累加，不保存全样本×候选×通道张量。额外CPU数组预算512MiB、CUDA allocated总上限1GiB，超过则停止提议并记录原因，不按结果更换分块或候选预算。每快照拟合库与评分共用一次带梯度提取，内部留出一次；批输出立即转CPU，图释放后再下一批。具体字节核算和实现前小诊断才可确认上限足够，当前是候选工程预算。

该提案仍是固定骨架上的部分结构优化。是否值得实施由root结合本轮证据决定；目前没有新任务前向、训练、GPU检查或新测试。
